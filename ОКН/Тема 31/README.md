# Определен интеграл: дефиниция, свойства и теорема на Нютон–Лайбниц

## 0. Голямата картина (защо изобщо правим всичко това?)

Искаме да дефинираме „площ под графиката на $f(x)$ върху $[a,b]$" по математически коректен начин, без да разчитаме на геометричната интуиция.

**Идеята на Дарбу:**
1. Разбиваме $[a,b]$ на много малки парчета.
2. Над всяко парче имаме два правоъгълника:
   - **малък** (с височина $\inf f$ над парчето) — *подценява* площта,
   - **голям** (с височина $\sup f$ над парчето) — *надценява* площта.
3. Истинската площ (ако такава смислено съществува) трябва да е *между* двете оценки.
4. Ако правейки разбиването все по-фино можем да направим разликата „надценка − подценка" *произволно малка*, значи има единствена стойност, която заслужава да се нарича „площ" → това е интегралът.

Така интегрируемост = двете оценки могат да се „залепят" до едно число.

---

## 1. Разбиване на интервал

**Дефиниция.** *Разбиване* на $[a,b]$ е краен набор от точки
$$\tau: a = x_0 < x_1 < x_2 < \cdots < x_n = b.$$
Точките $x_0, x_1, \ldots, x_n$ се наричат *делящи*.

Те раздробяват $[a,b]$ на $n$ затворени подинтервала $[x_{i-1}, x_i]$, $i = 1,\ldots,n$.

**Диаметър на разбиването:**
$$d(\tau) := \max_{i=1,\ldots,n}(x_i - x_{i-1}).$$
Това е дължината на *най-голямото* подпарче. Когато $d(\tau) \to 0$, *всички* подпарчета стават малки.

**Защо точно „макс"?** Защото за фините оценки ни трябва да *гарантираме*, че няма подпарче, което е останало едро. Едно голямо подпарче провaля цялата апроксимация.

---

## 2. Малки и големи суми на Дарбу

Нека $f:[a,b]\to\mathbb{R}$ е **ограничена** (важно условие — иначе $\inf$ и $\sup$ може да са $\pm\infty$).

За дадено разбиване $\tau$ полагаме над всяко подпарче $[x_{i-1},x_i]$:
$$m_i := \inf_{x\in[x_{i-1},x_i]} f(x), \qquad M_i := \sup_{x\in[x_{i-1},x_i]} f(x).$$

Тогава:
$$s_\tau := \sum_{i=1}^n m_i (x_i - x_{i-1}) \quad \text{(малка сума на Дарбу)},$$
$$S_\tau := \sum_{i=1}^n M_i (x_i - x_{i-1}) \quad \text{(голяма сума на Дарбу)}.$$

**Геометрична интерпретация (за положителна $f$):**
- $s_\tau$ = сума от площите на „вписаните" правоъгълници (тези, които са изцяло *под* графиката).
- $S_\tau$ = сума от площите на „описаните" правоъгълници (тези, които *покриват* графиката отгоре).

```
   y                                    y
   ^                                    ^
   |     ___                            |       ___
   |    |   |____                       |   ___|   |____
   |  __|   |    |                      |  |       |    |____
   | |  |   |    |__                    |  |       |    |    |
   | |__|___|____|__|___> x             |__|_______|____|____|___> x
        малка sτ                            голяма Sτ
   (под графиката)                      (над графиката)
```

Очевидно винаги:
$$s_\tau \leq S_\tau.$$

## 3. Какво става при добавяне на нови точки?

**Твърдение.** Ако $\tau' \supset \tau$ (т.е. $\tau'$ се получава от $\tau$ чрез добавяне на нови делящи точки), то:
$$s_{\tau'} \geq s_\tau, \qquad S_{\tau'} \leq S_\tau.$$

С думи: **по-фините разбивания дават по-добри оценки** — малките суми растат (или остават равни), големите намаляват (или остават равни).

### Доказателство (интуиция първо, после строго)

Достатъчно е да разгледаме случая, в който $\tau'$ има *само една* допълнителна точка спрямо $\tau$. (Общият случай е краен брой такива стъпки.)

Нека новата точка $c$ попадне в подинтервала $[x_{k-1}, x_k]$ на $\tau$. Тогава този подинтервал се разделя на два:
$$[x_{k-1}, c] \quad \text{и} \quad [c, x_k].$$

Всички останали подинтервали остават същите → техните приноси към сумите не се променят. Затова разликата идва само от подинтервала $[x_{k-1}, x_k]$.

Нека:
- $m_k = \inf f$ над целия $[x_{k-1}, x_k]$,
- $m_k' = \inf f$ над $[x_{k-1}, c]$,
- $m_k'' = \inf f$ над $[c, x_k]$.

**Ключово наблюдение:** Когато гледаме $\inf$ върху *по-малко* множество, той не може да *намалее* — има по-малко стойности, между които да избираме минимум. Затова:
$$m_k' \geq m_k, \quad m_k'' \geq m_k.$$

Сега:
$$s_{\tau'} - s_\tau = m_k'(c - x_{k-1}) + m_k''(x_k - c) - m_k(x_k - x_{k-1})$$
$$= \underbrace{(m_k' - m_k)}_{\geq 0}(c - x_{k-1}) + \underbrace{(m_k'' - m_k)}_{\geq 0}(x_k - c) \geq 0.$$

Значи $s_{\tau'} \geq s_\tau$. **Аналогично за големите суми** ($\sup$ върху по-малко множество не може да *расте*).

### Геометрична картинка

```
Преди (един правоъгълник):           След (два правоъгълника):
   ____________________                  __________
  |                    |                |          |________
  |        m_k         |  ←→            |   m_k'   |  m_k'' |
  |____________________|                |__________|________|
  x_{k-1}              x_k              x_{k-1}    c        x_k
```

Когато разрежем правоъгълника при $c$, можем да го „повдигнем" в участъци, където $f$ е по-голяма от $m_k$ → новата сума е $\geq$ старата.

### Следствие — всички малки суми ≤ всички големи

**Лема.** За *произволни* две разбивания $\tau_1, \tau_2$ имаме $s_{\tau_1} \leq S_{\tau_2}$.

**Доказателство.** Нека $\tau := \tau_1 \cup \tau_2$ (обединението на делящите точки). Тогава $\tau$ е по-фино и от двете:
$$s_{\tau_1} \leq s_\tau \leq S_\tau \leq S_{\tau_2}.$$

**Защо това е важно?** Означава, че множеството от *всички* малки суми лежи отляво на множеството от *всички* големи суми на числовата ос. Затова можем да дефинираме:
$$\underline{I} := \sup_\tau s_\tau \quad \text{(долен интеграл)},$$
$$\overline{I} := \inf_\tau S_\tau \quad \text{(горен интеграл)},$$
като автоматично $\underline{I} \leq \overline{I}$.

## 4. Дефиниция на риманов интеграл (подход на Дарбу)

**Дефиниция.** Функцията $f:[a,b]\to\mathbb{R}$ (ограничена) се нарича *интегруема по Риман* в $[a,b]$, ако
$$\underline{I} = \overline{I}.$$
В такъв случай общата стойност се нарича *определен интеграл на $f$ върху $[a,b]$* и се означава
$$\int_a^b f(x)\,dx.$$

**Превод:** интегруемост означава, че sup на малките суми и inf на големите *съвпадат*. Тоест има единствено число, разделящо двете множества.

---

## 5. Критерий за интегруемост ($S - s < \varepsilon$)

Това е **най-важният работен инструмент**: дава ни начин да *проверим* интегруемост, без да пресмятаме интеграла.

**Теорема (критерий на Дарбу).** Ограничена $f:[a,b]\to\mathbb{R}$ е интегруема ⟺
$$\forall \varepsilon > 0\ \exists\ \text{разбиване}\ \tau:\ S_\tau - s_\tau < \varepsilon.$$

**Интуиция:** интегруема ⟺ можем да направим „хлабината" между подоценка и надоценка по-малка от каквото и да е $\varepsilon$.

### Доказателство

**(⟹)** Нека $f$ е интегруема. Тогава $\underline{I} = \overline{I} =: I$.

Дайте ми $\varepsilon > 0$. Числото $I - \varepsilon/2$ *не е* горна граница на множеството $\{s_\tau\}$ (защото $I = \sup s_\tau$). Значи има $\tau_1$ с
$$s_{\tau_1} > I - \tfrac{\varepsilon}{2}.$$

Аналогично, $I + \varepsilon/2$ *не е* долна граница на $\{S_\tau\}$, така че има $\tau_2$ с
$$S_{\tau_2} < I + \tfrac{\varepsilon}{2}.$$

Изваждаме:
$$S_{\tau_2} - s_{\tau_1} < \varepsilon.$$

**Малък трик:** двете разбивания са *различни* и не можем директно да приберем $S$ и $s$ върху едно разбиване. Решението: вземаме $\tau := \tau_1 \cup \tau_2$ (по-фино от двете). Тогава:
$$s_{\tau_1} \leq s_\tau \leq S_\tau \leq S_{\tau_2},$$
откъдето
$$S_\tau - s_\tau \leq S_{\tau_2} - s_{\tau_1} < \varepsilon. \checkmark$$

**(⟸)** Обратно: за всяко $\varepsilon > 0$ има $\tau$ с $S_\tau - s_\tau < \varepsilon$. Но винаги:
$$s_\tau \leq \underline{I} \leq \overline{I} \leq S_\tau,$$
така че
$$0 \leq \overline{I} - \underline{I} \leq S_\tau - s_\tau < \varepsilon.$$

Понеже $\varepsilon$ беше произволно, $\overline{I} - \underline{I} = 0$, т.е. $f$ е интегруема. ∎

**Защо това е силно?** Не ни трябва да познаем стойността $I$ предварително — само да докажем, че разликата може да се направи малка. Идеален инструмент за теоретични доказателства.

## 6. Теорема: всяка непрекъсната функция в $[a,b]$ е интегруема

Това е едно от най-важните приложения на критерия по-горе.

**Теорема.** Ако $f:[a,b]\to\mathbb{R}$ е непрекъсната, то $f$ е интегруема по Риман в $[a,b]$.

### Подготовка — теорема на Кантор (използваме без доказателство)

> **Теорема на Кантор.** Всяка непрекъсната функция в *краен и затворен* интервал е *равномерно непрекъсната* там.

**Разлика между непрекъснатост и равномерна непрекъснатост:**
- *Непрекъснатост:* за всяка точка $x_0$ и за всяко $\varepsilon$ има $\delta = \delta(x_0, \varepsilon)$, така че $|x-x_0|<\delta \Rightarrow |f(x)-f(x_0)|<\varepsilon$. **Тук $\delta$ зависи от точката.**
- *Равномерна непрекъснатост:* за всяко $\varepsilon$ има *едно общо* $\delta = \delta(\varepsilon)$, което работи за *всички* двойки точки: $|x-y|<\delta \Rightarrow |f(x)-f(y)|<\varepsilon$.

Кантор гарантира, че на $[a,b]$ (компакт!) непрекъснатост ⟹ равномерна непрекъснатост. **Без този факт доказателството не минава** — нужно ни е едно $\delta$ за целия интервал.

### Доказателство на интегруемостта

Ще използваме критерия $S - s < \varepsilon$.

**Стъпка 1.** Фиксираме $\varepsilon > 0$. Искаме разбиване $\tau$ с $S_\tau - s_\tau < \varepsilon$.

**Стъпка 2.** Прилагаме Кантор: за числото $\frac{\varepsilon}{b-a} > 0$ има $\delta > 0$ такова, че
$$|x - y| < \delta \ \Rightarrow\ |f(x) - f(y)| < \frac{\varepsilon}{b-a}.$$

(Защо точно $\frac{\varepsilon}{b-a}$? Ще видим веднага — нагласяме си константата така, че накрая сумата да даде точно $\varepsilon$.)

**Стъпка 3.** Избираме каквото и да е разбиване $\tau$ с $d(\tau) < \delta$.

**Стъпка 4.** Над всеки подинтервал $[x_{i-1}, x_i]$ функцията $f$ е непрекъсната → по теоремата на Вайерщрас достига максимум и минимум. Нека $\xi_i, \eta_i \in [x_{i-1}, x_i]$ са точки, в които
$$f(\xi_i) = m_i, \quad f(\eta_i) = M_i.$$

Понеже $\xi_i, \eta_i$ са в подинтервал с дължина $< \delta$, имаме $|\xi_i - \eta_i| < \delta$, така че
$$M_i - m_i = f(\eta_i) - f(\xi_i) < \frac{\varepsilon}{b-a}.$$

**Стъпка 5.** Сега оценяваме:
$$S_\tau - s_\tau = \sum_{i=1}^n (M_i - m_i)(x_i - x_{i-1}) < \frac{\varepsilon}{b-a} \sum_{i=1}^n (x_i - x_{i-1}) = \frac{\varepsilon}{b-a}\cdot(b-a) = \varepsilon. \checkmark$$

Готово — критерият е изпълнен, $f$ е интегруема. ∎

> **Морал на доказателството:** равномерната непрекъснатост ни позволява да *контролираме осцилациите* на $f$ върху всеки подинтервал едновременно с *един* $\delta$. Без това не можем да гарантираме, че $M_i - m_i$ е малко *за всички* $i$.

## 7. Основни свойства на римановия интеграл (без доказателство)

Изброяваме ги — те се ползват без излишно мотане:

1. **Линейност:**
$$\int_a^b [\alpha f + \beta g]\,dx = \alpha\int_a^b f\,dx + \beta\int_a^b g\,dx.$$

2. **Адитивност по интервал:** за $c \in [a,b]$
$$\int_a^b f\,dx = \int_a^c f\,dx + \int_c^b f\,dx.$$

3. **Монотонност (интегриране на неравенства):** ако $f(x) \leq g(x)$ за всички $x \in [a,b]$, то
$$\int_a^b f\,dx \leq \int_a^b g\,dx.$$

4. **Модулно неравенство:**
$$\left|\int_a^b f\,dx\right| \leq \int_a^b |f|\,dx.$$

5. **Произведение на интегруеми е интегруемо** (полезно, но не пряко тук).

6. **Интегруемост и ограниченост:** всяка интегруема функция е ограничена.

## 8. Теорема за средните стойности (за интегралите)

**Теорема.** Ако $f$ е непрекъсната в $[a,b]$, то съществува $c \in [a,b]$ с
$$\boxed{\int_a^b f(x)\,dx = f(c)\cdot(b-a).}$$

**Геометрична интуиция:** има точка $c$, в която стойността $f(c)$ е „средната височина" на графиката — правоъгълник с тази височина и основа $b-a$ има същата площ като фигурата под графиката.

```
y                          
^         ___              
|     ___/   \             
|    /        \___         
|---/-------------\---  ← y = f(c)
|  /              |\       
| /               | \      
|/                |  \____ 
|_________________|_______ 
a              c         b
```

### Доказателство

**Стъпка 1.** Понеже $f$ е непрекъсната в компакта $[a,b]$, по Вайерщрас достига max и min:
$$m := \min_{[a,b]} f, \qquad M := \max_{[a,b]} f.$$

**Стъпка 2.** За всеки $x \in [a,b]$ имаме $m \leq f(x) \leq M$. Интегрираме това неравенство (свойство 3 — интегриране на неравенства):
$$\int_a^b m\,dx \leq \int_a^b f(x)\,dx \leq \int_a^b M\,dx,$$
т.е.
$$m(b-a) \leq \int_a^b f\,dx \leq M(b-a).$$

**Стъпка 3.** Делим на $b - a > 0$:
$$m \leq \underbrace{\frac{1}{b-a}\int_a^b f\,dx}_{=:\mu} \leq M.$$

Числото $\mu$ лежи между min и max на $f$.

**Стъпка 4.** Прилагаме теоремата за междинните стойности (Болцано–Коши): непрекъсната функция в $[a,b]$ приема *всяка* стойност между min и max. Значи има $c \in [a,b]$ с $f(c) = \mu$, откъдето
$$\int_a^b f\,dx = f(c)(b-a). \checkmark \ \blacksquare$$

> **Защо ни трябва това в Нютон–Лайбниц?** Защото ще искаме да оценим $\frac{1}{h}\int_{x_0}^{x_0+h} f(t)\,dt$ — а това точно е $f(c_h)$ за някое $c_h$ между $x_0$ и $x_0+h$. Когато $h \to 0$, $c_h \to x_0$, и по непрекъснатост $f(c_h) \to f(x_0)$.

## 9. Теорема на Нютон–Лайбниц (основна теорема на анализа)

Това е *кулминацията* на цялата тема.

**Теорема.** Нека $f:[a,b]\to\mathbb{R}$ е непрекъсната. Дефинираме
$$\Phi(x) := \int_a^x f(t)\,dt, \quad x \in [a,b].$$
Тогава $\Phi$ е диференцируема в $[a,b]$ и
$$\boxed{\Phi'(x) = f(x), \quad x \in [a,b].}$$

С други думи:
$$\frac{d}{dx}\int_a^x f(t)\,dt = f(x).$$

**Какво означава това на човешки език?** Ако фиксираме долната граница и помислим интеграла като функция на горната граница, то *производната на тази функция е подинтегралната функция*. Значи **интегрирането и диференцирането са взаимно обратни** (за непрекъснати функции).

### Доказателство

Фиксираме произволно $x_0 \in [a,b]$. Гледаме диференчното частно:
$$\frac{\Phi(x_0 + h) - \Phi(x_0)}{h}.$$

**Стъпка 1.** Разписваме разликата на двата интеграла. По свойство на адитивността:
$$\Phi(x_0 + h) - \Phi(x_0) = \int_a^{x_0+h} f(t)\,dt - \int_a^{x_0} f(t)\,dt = \int_{x_0}^{x_0+h} f(t)\,dt.$$

(Геометрично: от площта до $x_0+h$ изваждаме площта до $x_0$ → остава тънката лента между $x_0$ и $x_0+h$.)

**Стъпка 2.** Прилагаме теоремата за средните стойности (т. 8) върху интервала $[x_0, x_0+h]$ (или $[x_0+h, x_0]$, ако $h<0$):
$$\int_{x_0}^{x_0+h} f(t)\,dt = f(c_h)\cdot h,$$
където $c_h$ е някаква точка между $x_0$ и $x_0 + h$.

**Стъпка 3.** Делим на $h$:
$$\frac{\Phi(x_0 + h) - \Phi(x_0)}{h} = f(c_h).$$

**Стъпка 4.** Пускаме $h \to 0$. Понеже $c_h$ е *притиснато* между $x_0$ и $x_0+h$, имаме $c_h \to x_0$. По *непрекъснатостта* на $f$ в точката $x_0$:
$$\lim_{h\to 0} f(c_h) = f(x_0).$$

Следователно
$$\Phi'(x_0) = \lim_{h\to 0}\frac{\Phi(x_0+h) - \Phi(x_0)}{h} = f(x_0). \ \blacksquare$$

> **Къде се използва непрекъснатостта?** Точно в последната стъпка — без нея няма как да заключим $f(c_h) \to f(x_0)$. Това е причината теоремата да изисква *непрекъснатост*, а не само интегруемост.

### Следствие (за пресмятане на интеграли)

**Следствие (формула на Нютон–Лайбниц).** Ако $f$ е непрекъсната в $[a,b]$ и $G$ е *произволна* първообразна на $f$ (т.е. $G' = f$), то
$$\boxed{\int_a^b f(x)\,dx = G(b) - G(a).}$$

**Доказателство.** $\Phi$ е една първообразна на $f$ (по основната теорема). Двете първообразни на една и съща непрекъсната функция се различават с константа: $G(x) = \Phi(x) + C$.

При $x=a$: $\Phi(a) = \int_a^a f = 0$, така че $G(a) = C$.

При $x=b$: $G(b) = \Phi(b) + G(a) = \int_a^b f + G(a)$, откъдето:
$$\int_a^b f(x)\,dx = G(b) - G(a). \ \blacksquare$$

## 10. Как се ползва Нютон–Лайбниц за пресмятане

Формулата $\int_a^b f = G(b) - G(a)$ свежда пресмятането на определен интеграл до **две задачи**:

1. Намери *първообразна* $G$ (т.е. функция с $G' = f$) — това е задача от **неопределено интегриране** (таблици, смяна на променливата, по части и т.н.).
2. Пресметни $G(b) - G(a)$ (просто двe заместания).

### Примери

**Пример 1.** $\displaystyle \int_0^1 x^2\,dx$.

Първообразна: $G(x) = \frac{x^3}{3}$ (защото $G'(x) = x^2$).
$$\int_0^1 x^2\,dx = \frac{1^3}{3} - \frac{0^3}{3} = \frac{1}{3}.$$

**Пример 2.** $\displaystyle \int_0^{\pi/2} \cos x\,dx$.

Първообразна: $G(x) = \sin x$.
$$\int_0^{\pi/2} \cos x\,dx = \sin\tfrac{\pi}{2} - \sin 0 = 1 - 0 = 1.$$

**Пример 3.** $\displaystyle \int_1^e \frac{dx}{x}$.

Първообразна: $G(x) = \ln x$.
$$\int_1^e \frac{dx}{x} = \ln e - \ln 1 = 1 - 0 = 1.$$

### Стандартна нотация

Пишем $\left[G(x)\right]_a^b := G(b) - G(a)$, така че:
$$\int_a^b f(x)\,dx = \left[G(x)\right]_a^b.$$

### Защо това е революционно?

Преди Нютон и Лайбниц пресмятането на интеграли (площи) е било изключително трудно — нужни са били специфични трикове за всеки случай (метод на изчерпването на Архимед, infinitezimали и т.н.). Сега имаме *систематичен начин*: намираме първообразна и приключваме. Двете най-важни понятия в анализа — производна и интеграл — се оказват *обратни* едно на друго.

## Логическа карта на темата

```
       Разбиване на интервал
              │
              ▼
      Малки/Големи суми на Дарбу ────► Геометрия: ↓ s, ↑ S при добавяне на точки
              │
              ▼
       Долен/Горен интеграл (sup s, inf S)
              │
              ▼
    Дефиниция: интегруема ⟺ долен = горен
              │
              ▼
    Критерий: интегруема ⟺ ∀ε ∃τ: S-s<ε
              │
              ├─────► Кантор (равном. непр.) ─► Непр. ⟹ интегруема
              │
              ▼
    Свойства (линейност, адитивност, монотонност, ...)
              │
              ▼
   Теорема за средните стойности (Вайерщрас + Болцано-Коши)
              │
              ▼
   Нютон–Лайбниц: d/dx ∫_a^x f(t) dt = f(x)
              │
              ▼
   Формула: ∫_a^b f = G(b) - G(a)
              │
              ▼
   Пресмятане на конкретни интеграли (✓)
```

## Резюме на ключовите идеи

| Понятие | Същност | За какво ни служи |
|---|---|---|
| Разбиване | Дискретизация на $[a,b]$ | Превръща непрекъснат проблем в дискретен |
| Малка/голяма сума | Долна/горна оценка на „площта" | Между тях лежи интегралът |
| Доп. точки → ↓S, ↑s | Монотонност на оценките | Дава смисъл на „по-фино е по-добро" |
| $S - s < \varepsilon$ | Критерий за интегруемост | Не ни трябва да знаем $I$, за да докажем интегруемост |
| Кантор + критерий | Непрек. ⟹ интегр. | Нашите „хубави" функции са интегруеми |
| Теорема за средни ст-сти | $\int f = f(c)(b-a)$ | Свързва интеграла с *стойност* на $f$ |
| Нютон–Лайбниц | $\Phi' = f$ | Превръща интегрирането в обратна задача на диференцирането |
| $G(b) - G(a)$ | Практична формула | Пресмятаме интеграли с първообразни |
