# Как се смятат производни?
## Правила
| Правило | Формула | Кратко описание / Условие |
| --- | --- | --- |
| **Константа** | $(c)' = 0$ | Производната на самотно число е нула. |
| **Степенно** | $(x^n)' = n x^{n-1}$ | Сваляш степента отпред, намаляваш я с 1. |
| **Умножение с константа** | $(c \cdot f)' = c \cdot f'$ | Числото пред функцията не се променя. |
| **Сбор / Разлика** | $(f \pm g)' = f' \pm g'$ | Диференцираш всяко събираемо поотделно. |
| **Произведение** | $(f \cdot g)' = f'g + fg'$ | Производна на първото по второто + първото по производна на второто. |
| **Частно (Дроб)** | $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$ | Подобно на произведението, но с минус и разделено на знаменателя на квадрат. |
| **Верижно** | $(f(g(x)))' = f'(g(x)) \cdot g'(x)$ | Производна на "външната" функция по производна на "вътрешната". |
| **Правило на Лопитал** | $\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$ | Използва се **само** при търсене на граници, които дават неопределеност $\frac{0}{0}$ или $\frac{\infty}{\infty}$. |

## Производни на основните функции

### Тригонометрични функции
| Функция | Производна | Кратко описание / Условие |
| --- | --- | --- |
| $\sin x$ | $(\sin x)' = \cos x$ | Синус става косинус, без промяна на знака. |
| $\cos x$ | $(\cos x)' = -\sin x$ | Косинус става синус, но с минус отпред. |
| $\mathrm{tg}\,x$ | $(\mathrm{tg}\,x)' = \dfrac{1}{\cos^2 x}$ | Дефинирана за $x \neq \dfrac{\pi}{2} + k\pi$. Може и като $1 + \mathrm{tg}^2\,x$. |
| $\mathrm{ctg}\,x$ | $(\mathrm{ctg}\,x)' = -\dfrac{1}{\sin^2 x}$ | Дефинирана за $x \neq k\pi$. Може и като $-(1 + \mathrm{ctg}^2\,x)$. |

### Обратни тригонометрични функции
| Функция | Производна | Кратко описание / Условие |
| --- | --- | --- |
| $\arcsin x$ | $(\arcsin x)' = \dfrac{1}{\sqrt{1-x^2}}$ | Дефинирана за $-1 < x < 1$. |
| $\arccos x$ | $(\arccos x)' = -\dfrac{1}{\sqrt{1-x^2}}$ | Същата като на $\arcsin$, но с минус. За $-1 < x < 1$. |
| $\mathrm{arctg}\,x$ | $(\mathrm{arctg}\,x)' = \dfrac{1}{1+x^2}$ | Дефинирана за всяко реално $x$. |
| $\mathrm{arcctg}\,x$ | $(\mathrm{arcctg}\,x)' = -\dfrac{1}{1+x^2}$ | Като на $\mathrm{arctg}$, но с минус. |

### Степенни функции и корени
| Функция | Производна | Кратко описание / Условие |
| --- | --- | --- |
| $x^n$ | $(x^n)' = n x^{n-1}$ | Сваляш степента отпред, намаляваш я с 1. |
| $\sqrt{x}$ | $(\sqrt{x})' = \dfrac{1}{2\sqrt{x}}$ | За $x > 0$. Идва от $x^{1/2}$ по степенното правило. |
| $\sqrt[n]{x}$ | $(\sqrt[n]{x})' = \dfrac{1}{n \sqrt[n]{x^{n-1}}}$ | Идва от $x^{1/n}$. |
| $\dfrac{1}{x}$ | $\left(\dfrac{1}{x}\right)' = -\dfrac{1}{x^2}$ | За $x \neq 0$. Идва от $x^{-1}$. |

### Показателни (експоненциални) функции
| Функция | Производна | Кратко описание / Условие |
| --- | --- | --- |
| $e^x$ | $(e^x)' = e^x$ | Единствената функция, равна на собствената си производна. |
| $a^x$ | $(a^x)' = a^x \ln a$ | За $a > 0,\ a \neq 1$. При $a = e$ дава $e^x$. |

### Логаритмични функции
| Функция | Производна | Кратко описание / Условие |
| --- | --- | --- |
| $\ln x$ | $(\ln x)' = \dfrac{1}{x}$ | За $x > 0$. |
| $\log_a x$ | $(\log_a x)' = \dfrac{1}{x \ln a}$ | За $x > 0$, $a > 0,\ a \neq 1$. |
