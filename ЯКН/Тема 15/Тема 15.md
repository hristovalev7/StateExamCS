# Процедурно програмиране — указатели, масиви и рекурсия

## Увод

Процедурното програмиране организира програмата като съвкупност от функции (процедури), които обработват данни. В C++ програмистът има директен достъп до паметта чрез указатели — това позволява ефективна работа с масиви, низове и предаване на параметри, но изисква внимателно управление на паметта.

---

## 1. Указатели и указателна аритметика

### Тип указател

Ако `T` е тип данни, то `T*` е типът "указател към елемент от тип `T`". Стойността на един указател е **адрес** в паметта (цяло число), а специалната стойност `nullptr` означава "не сочи никъде". Указателите имат размера на машинната дума — 4 байта при 32-битова и 8 байта при 64-битова архитектура.

```cpp
int *pi;                  // неинициализиран указател
double *pd = nullptr;     // нулев указател
double d = 1.23;
double *qd = &d;          // сочи към d
double **qqd = &qd;       // указател към указател
```

### Основни операции

- **Рефериране** `&<lvalue>` — връща адреса на променлива (резултатът е rvalue);
- **Дерефериране** `*<указател>` — мястото в паметта, сочено от указателя (резултатът е lvalue);
- **Сравнение** — `==`, `!=`, `<`, `>` и т.н.;
- **Указателна аритметика** — `+`, `-`, `++`, `--`.

Двете операции са дуални: `&(*p) ⇔ p` и `*(&x) ⇔ x`.

```cpp
int x = 5, *p = &x;
int *q = p, y = *p + 2;   // y = 7
(*p)++;                   // x става 6
*q = 1;                   // x става 1 (q също сочи x)
```

### Указателна аритметика

Указателната аритметика позволява по дадена отправна точка (указател) да достигаме съседни клетки в паметта. Ключово: стъпката зависи от **типа**. Ако `T* p`, то `p + i` прескача `i * sizeof(T)` байта напред:

- `p + 2` при `char* p` → 2 байта напред;
- `p + 2` при `int* p` → 8 байта напред (при 4-байтов `int`);
- `p + 2` при `double* p` → 16 байта напред.

Операторът `sizeof(<тип>|<израз>)` връща размера в байтове. Разликата на два указателя от един тип `p - q` дава броя елементи между тях. Допустимо е и сравнение на указатели, сочещи в един масив.

### Връзка с масивите

> **Факт:** Името на масив е константен указател към първия му елемент. Освен това `a[i] ⇔ *(a + i)`.

```cpp
int a[5];
int* p = a;       // p сочи a[0]
*p = 15;          // a[0] = 15
*(a + 1) = 7;     // a[1] = 7
p++;              // ОК, p е променлива
a++;              // ГРЕШКА! a е константен указател
```

Любопитно следствие: `a[i] ⇔ *(a+i) ⇔ *(i+a) ⇔ i[a]`.

Чрез предаване на указател функция може да променя външни за нея променливи (предаване по адрес):

```cpp
void swap(int* x, int* y) {
    int tmp = *x; *x = *y; *y = tmp;
}
```

## 2. Едномерни и многомерни масиви

### Едномерни масиви

Масивът е **съставен тип данни**: крайна редица от елементи **от един и същи тип**, с произволен достъп до всеки елемент по номер (**индекс**).

Дефиниция:

```cpp
bool b[10];
double x[3] = { 0.5, 1.5, 2.5 };
int a[] = { 5, 8 };              // размерът се извежда: 2
float f[4] = { 2.3, 4.5 };       // останалите се допълват с 0
```

**Физическо представяне:** елементите са разположени последователно в непрекъснат блок памет. Масив от `n` елемента от тип `T` заема `n * sizeof(T)` байта.

**Индексиране:** `a[i]` може да е и lvalue (`a[i] = 7;`), и rvalue (`x = a[2];`). Важно: **няма проверка за коректност на индекса** — излизането извън границите е недефинирано поведение и отговорност на програмиста.

При предаване на масив към функция реално се предава указател към първия елемент, затова размерът се подава като отделен параметър:

```cpp
int sum(const int* a, int n) {
    int s = 0;
    for (int i = 0; i < n; i++)
        s += a[i];
    return s;
}
```

### Многомерни масиви

Многомерен масив е масив, чиито елементи са масиви (масив от n-мерни масиви е (n+1)-мерен).

```cpp
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};
double b[5][6] = {0.1, 0.2, 0.3, 0.4};   // запълва се ред по ред
```

Първата размерност може да се изпусне при наличие на инициализиращ списък. **Физическо представяне:** редовете са разположени последователно в паметта (ред по ред, "row-major"), т.е. двумерният масив е всъщност едномерен масив от редове. Затова елементът `a[i][j]` се намира на адрес `a + (i * <брой_колони> + j)` (в брой елементи). При предаване на двумерен масив към функция всички размерности освен първата трябва да са известни: `void f(int m[][3], int rows)`.

### Търсене в едномерен масив

**Линейно търсене** — обхождаме последователно; работи за произволен масив, сложност O(n):

```cpp
int linearSearch(const int* a, int n, int x) {
    for (int i = 0; i < n; i++)
        if (a[i] == x) return i;
    return -1;
}
```

**Двоично търсене** — изисква **сортиран** масив; на всяка стъпка сравняваме със средния елемент и отхвърляме половината масив; сложност O(log n):

```cpp
int binarySearch(const int* a, int n, int x) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) left = mid + 1;
        else            right = mid - 1;
    }
    return -1;
}
```

### Сортиране на едномерен масив

**Сортиране чрез пряка селекция (selection sort)** — на всяка стъпка намираме минималния елемент от несортираната част и го разменяме с първия ѝ елемент. Сложност O(n²):

```cpp
void selectionSort(int* a, int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[minIndex]) minIndex = j;
        if (minIndex != i)
            swap(&a[i], &a[minIndex]);
    }
}
```

**Метод на мехурчето (bubble sort)** — многократно обхождаме масива и разменяме съседни елементи в грешен ред; след всяко обхождане най-големият елемент "изплува" в края. Сложност O(n²):

```cpp
void bubbleSort(int* a, int n) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1])
                swap(&a[j], &a[j + 1]);
}
```

По-бърз е алгоритъмът за **бързо сортиране (quicksort)** със средна сложност O(n log n) — той е рекурсивен и е разгледан в т. 4.

## 3. Символни низове

### Представяне в паметта

**Низ** наричаме последователност от символи (последователност от 0 символа е празен низ). В C++ низът се представя като **масив от символи (`char`)**, в който след последния символ е записан **терминиращият символ `'\0'`** (първият символ в ASCII таблицата, с код 0).

```cpp
char word[] = { 'H', 'e', 'l', 'l', 'o', '\0' };
char s[] = "Hello";    // еквивалентно — компилаторът добавя '\0'
```

Низът `"Hello"` заема 6 байта: 5 символа + терминатор. Благодарение на `'\0'` дължината не се пази отделно — краят се открива при обхождане.

### Основни операции

- **Вход:** `std::cin >> s` чете до разделител (интервал, табулация, нов ред); `std::cin.getline(s, n)` чете цял ред, но не повече от n−1 символа;
- **Изход:** `std::cout << s` извежда до `'\0'`;
- **Индексиране:** `s[i]`;
- **Няма** присвояване `a = b` и поелементно сравнение `a == b` (сравняват се адреси!) — за тях има вградени функции от `<cstring>`:

| Функция | Действие |
|---|---|
| `strlen(s)` | дължина (без `'\0'`) |
| `strcpy(dest, src)` | копира `src` в `dest` |
| `strcat(dest, src)` | конкатенира `src` след `dest` |
| `strcmp(a, b)` | лексикографско сравнение: <0, 0 или >0 |

Тези функции лесно се реализират с указатели — низът е масив, а името му е указател:

```cpp
int myStrlen(const char* s) {
    int n = 0;
    while (*s++) n++;
    return n;
}

void myStrcpy(char* dest, const char* src) {
    while (*dest++ = *src++);   // копира и '\0'
}

int myStrcmp(const char* a, const char* b) {
    while (*a && *a == *b) { a++; b++; }
    return *a - *b;
}
```

### Типични проблеми

- **Излизане извън буфера (buffer overflow):** `strcpy` и `strcat` не проверяват дали в целевия масив има място — отговорност на програмиста. Ограничените варианти `strncpy`, `strncat`, `strncmp` работят с най-много n символа (но `strncpy` може да не запише `'\0'`, ако низът е по-дълъг от n!).
- **Нетерминирани низове:** ако липсва `'\0'` (напр. `char w[5] = {'H','e','l','l','o'};`), функциите като `strlen` четат отвъд масива — недефинирано поведение.

## 4. Рекурсия

### Дефиниция и принцип

> **Рекурсивна функция** наричаме функция, която извиква себе си **пряко или косвено**.

Рекурсията е вид **декомпозиция** — свеждане на задача към по-прости задачи, **подобни на първоначалната**. Всяко рекурсивно решение има две части:

1. **База (дъно)** — решение на най-простите случаи, при които няма рекурсивно извикване;
2. **Стъпка** — свеждане на по-сложна задача към една или няколко по-прости.

Без коректна база или без приближаване към нея рекурсията е безкрайна. Рекурсията съответства на математическата индукция, а класически пример е факториелът:

```cpp
unsigned long fact(unsigned n) {
    if (n == 0) return 1;        // база
    return n * fact(n - 1);      // стъпка
}
```

**Как работи в паметта:** при всяко извикване в програмния стек се създава нова **стекова рамка** с локалните променливи, параметрите и адреса на връщане. При `fact(4)` се натрупват рамки за n = 4, 3, 2, 1, 0, след което резултатите се "размотават" обратно. Затова рекурсията скрито използва памет и твърде дълбока рекурсия води до препълване на стека (stack overflow).

> **Теорема:** Всяка програма с цикли може да се напише с рекурсия и обратно.

### Пряка и косвена рекурсия

- **Пряка рекурсия** — функцията извиква директно себе си (`fact`).
- **Косвена (взаимна) рекурсия** — функцията извиква себе си през верига от други функции: f извиква g, а g извиква f.

```cpp
bool isOdd(unsigned n);   // предварителна декларация

bool isEven(unsigned n) {
    if (n == 0) return true;
    return isOdd(n - 1);
}
bool isOdd(unsigned n) {
    if (n == 0) return false;
    return isEven(n - 1);
}
```

### Линейна и разклонена рекурсия

- **Линейна рекурсия** — всяко извикване поражда **най-много едно** ново рекурсивно извикване (верига от извиквания). Примери: факториел, сума на елементи на масив:

```cpp
int sum(const int* a, int n) {
    if (n == 0) return 0;
    return a[n - 1] + sum(a, n - 1);
}
```

- **Разклонена (дървовидна) рекурсия** — извикване поражда **две или повече** рекурсивни извиквания; дървото на извикванията расте експоненциално. Класически пример са числата на Фибоначи:

```cpp
unsigned long fib(unsigned n) {
    if (n < 2) return n;
    return fib(n - 1) + fib(n - 2);     // две извиквания
}
```

Тук много стойности се пресмятат повторно (`fib(n)` прави ~2ⁿ извиквания) — пример как разклонената рекурсия може да е неефективна при неправилно използване; решава се с допълнителни параметри (линейна форма) или итерация.

### Рекурсия и масиви: бързо сортиране

Разклонената рекурсия е естествена за алгоритми тип **"разделяй и владей"**. Алгоритъм за бързо сортиране (quicksort):

1. Избираме елемент от масива ("ос", pivot);
2. Разделяме масива на две части: елементи, по-малки от оста, и елементи, по-големи или равни на нея;
3. Поставяме оста между двете части;
4. Рекурсивно сортираме поотделно двете части.

```cpp
void quickSort(int* a, int n) {
    if (n <= 1) return;                  // база
    int pivot = a[n / 2], i = 0, j = n - 1;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) swap(&a[i++], &a[j--]);
    }
    quickSort(a, j + 1);                 // лява част
    quickSort(a + i, n - i);             // дясна част (указ. аритметика!)
}
```

Средна сложност O(n log n), в най-лошия случай O(n²).

### Предимства и недостатъци на рекурсията

Предимства: силна изразителност, хубави математически свойства, удобна за задачи с рекурсивна постановка, за търсене с връщане назад (backtracking) и за алгоритми "разделяй и владей".

Недостатъци: скрито използване на памет за стекови рамки, може да е неефективна при неправилно използване (напр. наивното `fib`), изглежда сложна за неопитни програмисти.

## Заключение

Указателите дават директен достъп до паметта и са основата, върху която стъпват масивите (име на масив = константен указател, `a[i] ⇔ *(a+i)`) и низовете (масиви от `char` с терминатор `'\0'`). Върху масивите се дефинират фундаменталните алгоритми за търсене (линейно, двоично) и сортиране (селекция, мехурче, quicksort), а рекурсията предоставя мощен метод за декомпозиция, чиито разновидности — пряка/косвена и линейна/разклонена — покриват широк клас задачи.
