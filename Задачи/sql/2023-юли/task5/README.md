# Задача 5 - База данни Ships

## Описание на базата данни

Дадена е базата от данни **Ships**, в която се съхранява информация за кораби (Ships) и тяхното участие в битки (Battles) по време на Втората световна война. Всеки кораб е построен по определен стереотип, определящ класа на кораба (Classes).

### Таблица Classes

Съдържа информация за класовете кораби:

- `class` — име на класа, **първичен ключ**
- `type` — тип: `'bb'` за бойни кораби и `'bc'` за бойни крайцери
- `country` — държавата, която строи такива кораби
- `numGuns` — броят на основните оръдия
- `bore` — калибърът им (диаметърът на отвора на оръдието в инчове)
- `displacement` — водоизместимост в тонове

### Таблица Ships

Съдържа информация за корабите:

- `name` — име на кораб, **първичен ключ**
- `class` — име на неговия клас
- `launched` — годината, в която корабът е пуснат на вода

### Таблица Battles

Съхранява информация за битките:

- `name` — име на битката, **първичен ключ**
- `date` — дата на провеждане

### Таблица Outcomes

Съдържа информация за резултата от участието на даден кораб в дадена битка. Колоните `ship` и `battle` заедно формират **първичния ключ**:

- `ship` — име на кораба
- `battle` — име на битката
- `result` — резултат от битката: `'sunk'` за потънал, `'damaged'` за повреден и `'ok'` за победил

---

## Задача 1

### Условие

Да се напише заявка, която извежда **без повторение** имената на всички класове, от които няма нито един повреден в битка кораб. Ако даден клас няма никакви кораби или има, но те не са участвали в никакви битки, този клас също трябва да бъде изведен.

### Решение

```sql
SELECT DISTINCT class
FROM classes
WHERE class NOT IN (
    SELECT s.class
    FROM ships s
    JOIN outcomes o ON s.name = o.ship
    WHERE o.result != 'damaged'
)
```

## Задача 2

### Условие

Да се посочи коя от следните заявки извежда имената на класовете и броя на потъналите кораби от съответния клас. Ако даден клас има кораби, но нито един от тях не е потънал или нито един от тях не е участвал в битка, срещу неговото име заявката да извежда числото **0**. Ако даден клас няма никакви кораби, неговото име да **НЕ** се извежда.

**А)**

```sql
SELECT class, COUNT(ship)
FROM Ships
LEFT JOIN Outcomes
ON Ships.name = Outcomes.ship
AND result = 'sunk'
GROUP BY class;
```

**Б)**

```sql
SELECT DISTINCT class,
       (SELECT COUNT(*)
        FROM Outcomes
        WHERE result = 'sunk')
FROM Ships;
```

**В)**

```sql
SELECT class, COUNT(result = 'sunk')
FROM Ships
JOIN Outcomes
ON Ships.name = Outcomes.ship
GROUP BY class
HAVING COUNT(*) = 0;
```

**Г)**

```sql
SELECT c.class, COUNT(DISTINCT result)
FROM Outcomes o
RIGHT JOIN Ships s ON o.ship = s.name
RIGHT JOIN Classes c
ON s.class = c.class
WHERE result = 'sunk'
GROUP BY c.class;
```

### Решение

**Правилният отговор е А).**

**Анализ на вариантите:**

**А) Верен** ✅

```sql
SELECT class, COUNT(ship)
FROM Ships
LEFT JOIN Outcomes ON Ships.name = Outcomes.ship AND result = 'sunk'
GROUP BY class;
```

- **LEFT JOIN** гарантира, че всички кораби от `Ships` ще бъдат включени
- Условието `result = 'sunk'` е в **ON клаузата**, така че match-ва само потъналите кораби
- За кораби без битки или непотънали, `Outcomes.ship` ще е `NULL`
- **COUNT(ship)** брои ненулевите стойности от колоната `ship` на таблицата `Outcomes`
- За класове без потънали кораби, COUNT ще върне **0** (защото всички Outcomes.ship са NULL)
- За класове с потънали кораби, COUNT ще върне броя на потъналите
- **Класове без кораби НЕ се показват**, защото започваме от `Ships` (няма редове за групиране)
- **Коректен:** Отговаря на всички изисквания

**Б) Грешен** ❌

```sql
SELECT DISTINCT class,
       (SELECT COUNT(*) FROM Outcomes WHERE result = 'sunk')
FROM Ships;
```

- Подзаявката `COUNT(*)` брои **ВСИЧКИ** потънали кораби в цялата база данни
- Този брой е **глобален**, не е специфичен за класа
- Всички класове ще покажат **същия** брой (общия брой потънали кораби)
- **Грешка:** Не брои по класове, а показва глобална статистика

**В) Грешен** ❌

```sql
SELECT class, COUNT(result = 'sunk')
FROM Ships
JOIN Outcomes ON Ships.name = Outcomes.ship
GROUP BY class
HAVING COUNT(*) = 0;
```

- **INNER JOIN** (просто `JOIN`) включва само кораби, които са участвали в битки
- **HAVING COUNT(\*) = 0** търси групи с 0 реда
- Но след INNER JOIN и GROUP BY не може да има групи с 0 реда (групи се създават само за съществуващи комбинации)
- **COUNT(result = 'sunk')** е неправилен синтаксис в стандартен SQL (трябва да е в CASE изразение)
- Дори да бъде коригирано, HAVING COUNT(\*) = 0 никога няма да върне резултат
- **Грешка:** Логически невъзможна заявка, неправилен синтаксис

**Г) Грешен** ❌

```sql
SELECT c.class, COUNT(DISTINCT result)
FROM Outcomes o
RIGHT JOIN Ships s ON o.ship = s.name
RIGHT JOIN Classes c ON s.class = c.class
WHERE result = 'sunk'
GROUP BY c.class;
```

- **RIGHT JOIN Classes** означава всички класове (вкл. без кораби)
- **WHERE result = 'sunk'** филтрира СЛЕД JOIN операциите
- WHERE клаузата премахва всички редове, където `result` не е `'sunk'` (вкл. NULL-ове)
- Класове без потънали кораби **НЕ** се показват (защото WHERE премахва редовете с NULL или други резултати)
- **COUNT(DISTINCT result)** брои уникални резултати - но тъй като филтрираме само `'sunk'`, винаги ще е 1 (или 0 ако няма редове за групата, което е невъзможно след WHERE)
- **Грешка:** WHERE клаузата унищожава ефекта на RIGHT JOIN, не показва класове с 0 потънали кораби

## Ключови концепции

1. **LEFT JOIN vs INNER JOIN:**
   - LEFT JOIN запазва всички редове от лявата таблица
   - INNER JOIN включва само редове със съвпадения в двете таблици

2. **ON vs WHERE:**
   - ON условията се прилагат **по време** на JOIN операцията
   - WHERE условията се прилагат **СЛЕД** JOIN операцията
   - При LEFT JOIN, условия за дясната таблица трябва да са в ON, за да запазим левите редове

3. **COUNT(column) vs COUNT(\*):**
   - COUNT(\*) брои всички редове (вкл. NULL-ове)
   - COUNT(column) брои само ненулевите стойности в колоната

4. **NOT EXISTS:**
   - Проверява дали подзаявката връща поне един ред
   - Ефективно за проверка на отсъствие на определени условия

5. **GROUP BY с LEFT JOIN:**
   - LEFT JOIN + GROUP BY + COUNT(right_column) е мощен pattern за броене със 0 за липсващи съвпадения
