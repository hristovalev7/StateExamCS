# Задача 4 - Функционално програмиране (Haskell)

## Условие

Крайно кореново дърво, всеки връх на което съдържа цяло число и може да има произволен брой деца, се представя в Haskell със следната рекурсивна структура:

```haskell
data Tree = T { root :: Int, subtrees :: [Tree] } deriving Show
```

**Дефиниции:**

- **Листо** - дърво с единствен връх
- **Клонка** - дърво, чиито директни поддървета са листа
- **Пръчка** - дърво, в което всеки връх има най-много едно дете

**Операции:**

- **Подрязване (trim)** - премахват се всички клонки, с изключение на корена
- **Окастряне (prune)** - всички пръчки с повече от два върха, които не са част от други пръчки, се скъсяват откъм листата до дължина точно два върха

Да се попълнят празните полета, така че:

- функциите `leaf`, `twig` и `stick` да проверяват дали дърво е съответно листо, клонка или пръчка
- функциите `trim` и `prune` да връщат съответно подрязано или окастрено копие на дървото

---

## Примерно решение:

```haskell
-- Проверка дали дърво е листо (няма поддървета)
leaf t = null (subtrees t)

-- Проверка дали дърво е клонка (всички деца са листа и има поне едно дете)
twig t = not (null (subtrees t)) && all (\child -> leaf child) (subtrees t)

-- Проверка дали дърво е пръчка (всеки връх има най-много едно дете)
stick (T _ [t]) = stick t      -- Рекурсивен случай: един наследник
stick (T _ ts) = null ts       -- Базов случай: няма деца (листо) или повече от едно дете

-- Подрязване: премахва всички клонки от поддърветата (освен корена)
trim (T x ts) = T x [ trim t | t <- ts, not (twig t) ]

-- Окастряне: скъсява пръчките до дължина точно 2 върха
prune t@(T x ts)
  | null ts = t                                  -- Листо - не променяме
  | stick t = T x [T (root (head ts)) []]        -- Пръчка - скъсяваме до 2 върха
  | otherwise = T x (map prune ts)               -- Рекурсивно обработваме децата
```

---

## Алтернативен вариант на prune:

```haskell
prune t@(T x []) = T x []                        -- Листо
prune t@(T x ts)
  | stick t = T x [T (root (head ts)) []]        -- Пръчка
  | otherwise = T x (map prune ts)               -- Дърво с разклонения
```

---

## Обяснения:

### `twig`

Трябва да проверим:

1. Дървото не е листо (има поне едно дете) - `not (null (subtrees t))`
2. Всички деца са листа - `all (\child -> leaf child) (subtrees t)`

### `stick`

Пръчка е дърво, където всеки връх има най-много едно дете:

- Ако има точно едно дете `[t]`, проверяваме рекурсивно това дете
- Иначе проверяваме дали списъкът е празен (листо) или има повече от едно дете (не е пръчка)

### `trim`

Премахва всички клонки от поддърветата, като филтрира само тези, които не са клонки `not (twig t)`, и рекурсивно обработва останалите.

### `prune`

Окастря пръчките до дължина 2:

- Ако е листо `(null ts)` - оставя го непроменено
- Ако е пръчка `(stick t)` - взима корена и единственото му дете, създавайки дърво с височина 2
- Иначе рекурсивно обработва всички поддървета
