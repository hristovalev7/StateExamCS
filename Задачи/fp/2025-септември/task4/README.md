# Задача 4

Задачата да се реши на един от езиците **Haskell** или **Scheme**.

## Условие

Назначение на служител по проект се задава с наредена тройка (списък от три елемента за Scheme):

- име на служител (низ)
- име на проект (низ)
- процент заетост (цяло положително число < 100)

**Обща заетост на служител** наричаме сумата от процентите заетост по всички проекти, по които е назначен.

Нека е даден глобално дефиниран списък с назначения `work`, в който считаме, че няма две назначения на един и същи служител към един и същи проект.

---

## Задачи

Да се попълнят празните места по-долу, така че:

### а) `empAssignments`

Да връща списък от всички назначения на служителя `emp` в `work`.

```haskell
empAssignments :: String -> [(String, String, Int)]
empAssignments emp = filter (\(e,_,_) -> e == emp) work
```

### б) `totalLoad`

Да връща общата заетост на служителя `emp` в `work`.

```haskell
totalLoad :: String -> Int
totalLoad emp = sum (map (\(_,_,l) -> l) (empAssignments emp))
```

### в) `overloaded`

Да връща назначенията на служителите, чиято обща заетост надвишава 100%.

```haskell
overloaded :: [(String, String, Int)]
overloaded = filter (\(e,_,_) -> totalLoad e > 100) work
```

**Алтернативен вариант** (връща имената на претоварените служители без повторения):

```haskell
overloaded2 :: [String]
overloaded2 = nub (map (\(e,_,_) -> e) (filter (\(e,_,_) -> totalLoad e > 100) work))
```

### г) `minLoad`

Да проверява дали подаденото като параметър назначение е „минимално" в проекта си, т.е. заетостта в него не надвишава заетостта на нито едно от назначенията в `work` за същия проект.

```haskell
minLoad :: (String, String, Int) -> Bool
minLoad (_, project, load) = load <= minimum [ l | (_, p, l) <- work, p == project]
```

### д) `optimize`

Да връща копие на `work`, в което за всеки служител, който има точно едно минимално назначение, е увеличена заетостта му по това назначение така, че общата му заетост да стане 100%, но само когато тя е била под 100% в `work`. Останалите назначения на служителя се запазват.

```haskell
optimize :: [(String, String, Int)]
optimize = map (\r@(emp,project, load) ->
                    let t = totalLoad emp
                    in if (t < 100 && minLoad r && length (filter minLoad (empAssignments emp)) == 1)
                       then (emp, project, load + (100 - t))
                       else r) work
```

## Примерни данни

```haskell
work = [ ("X","A",40), ("X","B",30), ("Y","A",60), ("Y","C",50), ("Z","B",20), ("Z","C",20) ]
```

### Примерни резултати:

```haskell
empAssignments "X" ⟶ [ ("X","A",40), ("X","B",30) ]

totalLoad "Y" ⟶ 110

overloaded ⟶ [ ("Y","A",60), ("Y","C",50) ]

minLoad ("Z","C",20) ⟶ True
minLoad ("X","B",30) ⟶ False

optimize ⟶ [("X","A",70), ("X","B",30), ("Y","A",60), ("Y","C",50), ("Z","B",20), ("Z","C",20)]
```

**Обяснение на `optimize`:**

- Служител X има обща заетост 70% (< 100) и има точно едно минимално назначение (A,40), затова заетостта му по проект A се увеличава с 30% → (X,A,70)
- Служител Y е претоварен (110% > 100), не се променя
- Служител Z има два минимални проекта (B и C са с еднаква заетост 20%), не се променя
