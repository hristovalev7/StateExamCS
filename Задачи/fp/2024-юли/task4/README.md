# Задача 4

Задачата да се реши на езика **Haskell** или Scheme.

## Условие

Амбициозната стартъп компания „Crypto Quantum AI" провела масова рекламна кампания в социалната мрежа Y, за да привлече максимален брой потребители за новия си революционен продукт. Мрежата Y предоставя функция `clicks`, която по подаден идентификатор на реклама (низ) връща списък от идентификатори на потребители (цели числа), които са посетили рекламната връзка.

За следващата кампания в социалната мрежа Lambda, компанията иска да намали броя на рекламите, за които плаща. Да се реализира функция `redundant`, която по подадена функция `clicks` и множество реклами `ads` връща множество от реклами, за всяка от които е вярно, че **ако се премахне от кампанията, множеството на привлечените потребители ще остане без промяна**.

За целта да се реализират следните помощни функции:

**Забележка:** В тази задача множествата се представят като списъци без повторения.

**Упътване:** Позволено е използването на функциите `all`, `elem`, `filter`, `foldr`, `map`, `not`, както и на всички функции от R5RS и Prelude.

### Пример:

```haskell
clicks "a" = [1,2,3]
clicks "b" = [1,3,5]
clicks "c" = [2,3,5,7]
```

### Очаквани резултати:

```haskell
union [1,3,4] [4,1,7] ⟶ [3,4,1,7]
subset [1,2] [3,2,1] ⟶ True
collect clicks ["a", "b", "c"] ⟶ [1,2,3,5,7]
redundant clicks ["a", "b", "c"] ⟶ ["a", "b"]
```

## а) union - обединение на две множества

Да се реализира функция `union`, която намира обединението на две множества от цели числа.

```haskell
union xs ys =
```

### Решение:

```haskell
union xs ys = xs ++ [ y | y <- ys, not $ y `elem` xs]
```

**Обяснение:**

- Взима всички елементи от `xs`
- Добавя само тези елементи от `ys`, които **не са** в `xs`
- `[ y | y <- ys, not $ y `elem` xs]` - list comprehension, филтрира елементите на `ys`
- `not $ y `elem` xs` - проверява дали `y` не е елемент на `xs`
- Резултатът е списък без дублиращи се елементи

**Алтернативно решение с filter:**

```haskell
union xs ys = xs ++ filter (\y -> not $ y `elem` xs) ys
```

**Пример:** `union [1,3,4] [4,1,7]` → `[1,3,4,7]`

---

## б) subset - проверка за подмножество

Да се реализира функция `subset`, която реализира релацията „подмножество" за множества от цели числа.

```haskell
subset xs ys =
```

### Решение:

```haskell
subset xs ys = all (\x -> x `elem` ys) xs
```

**Обяснение:**

- Проверява дали **всички** елементи от `xs` се съдържат в `ys`
- `all` връща `True` ако всички елементи удовлетворяват предиката
- `\x -> x `elem` ys` - проверява дали `x` е елемент на `ys`
- Ако всички елементи на `xs` са в `ys`, тогава `xs` е подмножество на `ys`

**Пример:** `subset [1,2] [3,2,1]` → `True`

---

## в) collect - събиране на всички потребители

Да се реализира функция `collect`, която по подадена функция `clicks` и списък от реклами връща множество от всички потребители, които са посетили връзката на поне една реклама.

```haskell
collect clicks ads = foldr       ads
```

### Решение:

```haskell
collect clicks ads = foldr union [] (map clicks ads)
```

**Обяснение:**

**Ред на изпълнение:**

1. **`map clicks ads`** - прилага `clicks` върху всяка реклама
   - `clicks "a"` → `[1,2,3]`
   - `clicks "b"` → `[1,3,5]`
   - `clicks "c"` → `[2,3,5,7]`
   - Резултат: `[[1,2,3], [1,3,5], [2,3,5,7]]`

2. **`foldr union []`** - обединява всички списъци отдясно наляво
   - Начална стойност: `[]`
   - Стъпка 1: `union [2,3,5,7] []` → `[2,3,5,7]`
   - Стъпка 2: `union [1,3,5] [2,3,5,7]` → `[1,3,5,2,7]`
   - Стъпка 3: `union [1,2,3] [1,3,5,2,7]` → `[1,2,3,5,7]`
   - Краен резултат: `[1,2,3,5,7]`

**Защо foldr?**

- `foldr` обработва списъка отдясно наляво
- Обединява всички множества в едно
- Използва `union`, за да избегне дублиращи се елементи

**Пример:** `collect clicks ["a", "b", "c"]` → `[1,2,3,5,7]`

## г) redundant - намиране на излишни реклами

Да се реализира функция `redundant`, която по подадена функция `clicks` и множество реклами `ads` връща множество от реклами, за всяка от които е вярно, че ако се премахне от кампанията, множеството на привлечените потребители ще остане без промяна.

```haskell
redundant clicks ads = filter (\ad -> subset
                              (collect clicks          )) ads
```

### Решение:

```haskell
redundant clicks ads = filter (\ad -> subset (clicks ad) (collect clicks (filter (\x -> x /= ad) ads))) ads
```

**Обяснение:**

Реклама е излишна, ако **нейните потребители са покрити от останалите реклами**.

**Логика на функцията:**

За всяка реклама `ad`:

1. **`clicks ad`** - потребителите на текущата реклама
2. **`filter (\x -> x /= ad) ads`** - всички реклами **без** текущата
3. **`collect clicks (filter (\x -> x /= ad) ads)`** - всички потребители от останалите реклами
4. **`subset (clicks ad) (...)`** - проверява дали потребителите на `ad` са подмножество на потребителите от останалите

Ако е `True`, рекламата е излишна (може да се премахне без загуба на потребители).

**Детайлен пример:**

Дадено:

- clicks "a" = [1,2,3]
- clicks "b" = [1,3,5]
- clicks "c" = [2,3,5,7]

**Проверка за "a":**

- Потребители на "a": `[1,2,3]`
- Останали реклами: `["b", "c"]`
- Потребители от "b" + "c": `collect clicks ["b","c"]` → `[1,3,5,2,7]`
- `subset [1,2,3] [1,3,5,2,7]` → **True** ✓ ("a" е излишна)

**Проверка за "b":**

- Потребители на "b": `[1,3,5]`
- Останали реклами: `["a", "c"]`
- Потребители от "a" + "c": `collect clicks ["a","c"]` → `[1,2,3,5,7]`
- `subset [1,3,5] [1,2,3,5,7]` → **True** ✓ ("b" е излишна)

**Проверка за "c":**

- Потребители на "c": `[2,3,5,7]`
- Останали реклами: `["a", "b"]`
- Потребители от "a" + "b": `collect clicks ["a","b"]` → `[1,2,3,5]`
- `subset [2,3,5,7] [1,2,3,5]` → **False** ✗ (7 липсва! "c" е необходима)

**Резултат:** `["a", "b"]` - само тези две реклами са излишни, защото само "c" привлича уникален потребител (7).

**Пример:** `redundant clicks ["a", "b", "c"]` → `["a", "b"]`

## Пълно решение:

```haskell
-- а) Обединение на две множества
union xs ys = xs ++ [ y | y <- ys, not $ y `elem` xs]

-- б) Проверка за подмножество
subset xs ys = all (\x -> x `elem` ys) xs

-- в) Събиране на всички потребители
collect clicks ads = foldr union [] (map clicks ads)

-- г) Намиране на излишни реклами
redundant clicks ads = filter (\ad -> subset (clicks ad) (collect clicks (filter (\x -> x /= ad) ads))) ads

-- Примерна функция clicks
clicks "a" = [1,2,3]
clicks "b" = [1,3,5]
clicks "c" = [2,3,5,7]

-- Тестване
main :: IO ()
main = do
  print $ union [1,3,4] [4,1,7]              -- [1,3,4,7]
  print $ subset [1,2] [3,2,1]               -- True
  print $ collect clicks ["a", "b", "c"]     -- [1,2,3,5,7]
  print $ redundant clicks ["a", "b", "c"]   -- ["a","b"]
```

## Ключови концепции:

1. **Множества като списъци**: Списъци без повторения
2. **union**: Обединение чрез добавяне на уникални елементи
3. **subset**: Проверка дали всички елементи на първото са във второто
4. **foldr**: Натрупване отдясно наляво за обединяване на множества
5. **filter**: Филтриране на елементи според предикат
6. **List comprehension**: Компактен синтаксис за филтриране и трансформация
7. **Излишни реклами**: Реклами, чиито потребители са покрити от други
