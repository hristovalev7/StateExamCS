# Задача 4 - Генериране на функционални изрази (ChatFOS 5)

## Описание

Моделът „ChatFOS 5" може да генерира прости функционални изрази, съдържащи една променлива `x` и извиквания на двуместни числови функции от предварително зададена „библиотека", които моделът познава и може да използва.

**Библиотеката** се представя със списък от наредени двойки: символ на функцията и самата функция.

**Изразите на Haskell** са представени с дървета от следния алгебричен тип:

```haskell
data Expr = N Integer | X | F Char Expr Expr
```

където:

- Конструкторът `N` представя числова константа
- `X` представя променливата на израза
- `F` представя функция със зададен символ и два израза за аргументи

**Примерни дефиниции:**

```haskell
exprs = [F '-' (F '*' X X) (N 1), F '+' (F '*' X (N 2)) (N 3),
         F '*' (F '*' X X) (F '+' X (N 2)), F '+' (F '^' X (N 3)) (N 1)]

lib = [('+',(+)),('-',(-)),('*',(*))]
```

**Примерно извикване:**

```haskell
score (-10) 10 lib [\x -> x^2-1, \x -> x*3+2, \x -> x^3+2*x^2, \x -> x^3+1] exprs
```

---

## а) Функция correct - проверка за коректност на израз

### Условие

Функцията `correct` да проверява дали даденият израз е коректно построен само чрез функциите от библиотеката `lib`, цели числа и символа `x`.

### Решение

```haskell
correct lib (F f l r) = elem f (map (\(x,y) -> x) lib) && correct lib l && correct lib r
correct _   (N _)     = True
correct _   X         = True
```

---

## б) Функция calc - изчисляване на израз

### Условие

Функцията `calc` да връща едноместната функция, пресмятана от даден израз при библиотека от функции `lib`, като допуска, че изразът е коректно построен.

### Решение

```haskell
calc lib (N n) _ = n
calc lib X     x = x
calc lib (F c l r) x = (head [f | (fc, f) <- lib, fc == c]) (calc lib l x) (calc lib r x)
```

---

## в) Функция check - проверка за коректност на генериран израз

### Условие

Функцията `check` да проверява дали генерираният израз `expr` правилно пресмята функцията `f`, като проверява дали те връщат еднакви стойности над всички цели числа в интервала [a; b].

### Решение

```haskell
check a b lib f expr = all (\x -> correct lib expr && calc lib expr x == f x) [a..b]
```

---

## г) Функция score - точност на модела

### Условие

Функцията `score` намира точността на модела (число в интервала [0; 1]) като по дадени списъци `exprs` от генерирани изрази и `fs` от функции, които те би трябвало да пресмятат, чрез `check` намира отношението на броя на правилно пресметнатите функции към броя на всички функции.

### Решение

```haskell
score a b lib fs exprs = fromIntegral (length (filter id (zipWith (check a b lib) fs exprs)))
                         / fromIntegral (length fs)
```

## Пълна програма

```haskell
data Expr = N Integer | X | F Char Expr Expr

exprs = [F '-' (F '*' X X) (N 1), F '+' (F '*' X (N 2)) (N 3),
         F '*' (F '*' X X) (F '+' X (N 2)), F '+' (F '^' X (N 3)) (N 1)]

lib = [('+',(+)),('-',(-)),('*',(*))]

correct lib (F f l r) = elem f (map (\(x,y) -> x) lib) && correct lib l && correct lib r
correct _   (N _)     = True
correct _   X         = True

calc lib (N n) _ = n
calc lib X     x = x
calc lib (F c l r) x = (head [f | (fc, f) <- lib, fc == c]) (calc lib l x) (calc lib r x)

check a b lib f expr = all (\x -> correct lib expr && calc lib expr x == f x) [a..b]

score a b lib fs exprs = fromIntegral (length (filter id (zipWith (check a b lib) fs exprs)))
                         / fromIntegral (length fs)

main :: IO ()
main = do
  print (score (-10) 10 lib [\x -> x^2-1, \x -> x*3+2, \x -> x^3+2*x^2, \x -> x^3+1] exprs)
```

---

## Обяснение

### correct - Проверка за коректност

- **`correct lib (F f l r)`** - проверява дали функцията `f` съществува в библиотеката и рекурсивно проверява левия и десния подизрази
- **`elem f (map (\(x,y) -> x) lib)`** - извлича всички символи от библиотеката и проверява дали `f` е измежду тях
- **`correct _ (N _)`** - числовите константи са винаги коректни
- **`correct _ X`** - променливата `x` е винаги коректна

### calc - Изчисляване на израз

- **`calc lib (N n) _`** - константите връщат своята стойност (независимо от `x`)
- **`calc lib X x`** - променливата връща стойността на `x`
- **`calc lib (F c l r) x`** - намира функцията с символ `c` от библиотеката и я прилага над изчислените стойности на левия и десния подизрази
- **`head [f | (fc, f) <- lib, fc == c]`** - търси функцията със символ `c` в библиотеката

### check - Проверка в интервал

- **`all (\x -> ...) [a..b]`** - проверява дали за всяко `x` в интервала [a, b]:
  - Изразът е коректен: `correct lib expr`
  - Изразът пресмята същата стойност като функцията: `calc lib expr x == f x`

### score - Точност на модела

- **`zipWith (check a b lib) fs exprs`** - създава списък от булеви стойности, като проверява всяка двойка (функция, израз)
- **`filter id`** - филтрира само `True` стойностите
- **`fromIntegral (length ...))`** - преобразува броя в дробно число
- **Връща:** отношението на правилните изрази към общия брой изрази (стойност в [0; 1])

## Примерни изрази

1. **`F '-' (F '*' X X) (N 1)`** → `x*x - 1` → `x^2 - 1` ✅
2. **`F '+' (F '*' X (N 2)) (N 3)`** → `x*2 + 3` ❌ (трябва `x*3 + 2`)
3. **`F '*' (F '*' X X) (F '+' X (N 2))`** → `x*x * (x+2)` → `x^2 * (x+2)` = `x^3 + 2x^2` ✅
4. **`F '+' (F '^' X (N 3)) (N 1)`** → `x^3 + 1` ✅ (ако `^` е в библиотеката)

**Резултат:** 3/4 = 0.75 (75% точност)
