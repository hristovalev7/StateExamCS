## 1) Довършване на функцията power

### Условие

Да се довърши кода на `power` така, че тя да пресмята повдигането на `base` на степен `power`.

```cpp
int power(int base, unsigned int power)
{
    int result = _______________________;
    while(power > _________________) {
        if(power % 2 == __________) {
            ____________ = result * base;
        }
        __________ /= 2;
        __________ *= base;
    }
    return result;
}
```

### Решение

```cpp
int power(int base, unsigned int power)
{
    int result = 1;
    while(power > 0) {
        if(power % 2 == 1) {
            result = result * base;
        }
        power /= 2;
        base *= base;
    }
    return result;
}
```

**Обяснение:**

- Използва се алгоритъмът **"бързо степенуване" (Exponentiation by squaring)**
- **result = 1** - началната стойност е 1 (неутрален елемент за умножение)
- **power > 0** - докато има още степени за обработка
- **power % 2 == 1** - ако степента е нечетна, умножаваме result с текущата база
- **result = result \* base** - натрупваме резултата при нечетни степени
- **power /= 2** - делим степента на 2 (обработваме битовете отдясно наляво)
- **base \*= base** - удвояваме базата (base² → base⁴ → base⁸...)
- **Сложност:** O(log n), където n е степента - много по-бързо от O(n) наивния алгоритъм

**Пример:** 3⁵ = 243

- Итерация 1: power=5 (нечетно) → result=1×3=3, power=2, base=9
- Итерация 2: power=2 (четно) → power=1, base=81
- Итерация 3: power=1 (нечетно) → result=3×81=243, power=0, base=6561
- Резултат: 243

## 2) Числови литерали

### Условие

Да се посочи какво ще изведе на екрана дадения по-долу фрагмент.

```cpp
int a=10, b=010, c=0x10;
cout << a << ", " << b << ", " << c;
```

### Решение

**Изход:** `10, 8, 16`

**Обяснение:**

- **a = 10** - десетично число (base 10), стойност = 10
- **b = 010** - осмично число (base 8), защото започва с 0
  - 010₈ = 1×8¹ + 0×8⁰ = 8₁₀
- **c = 0x10** - шестнадесетично число (base 16), защото започва с 0x
  - 0x10₁₆ = 1×16¹ + 0×16⁰ = 16₁₀
- По подразбиране `cout` извежда числата в десетична бройна система

## 3) while и do-while цикли

### Условие

Под всеки от фрагментите да се посочи какво ще изведе той на екрана.

**Фрагмент 1:**

```cpp
int var = 0;
while(var++ < 5)
    cout << var;
```

**Фрагмент 2:**

```cpp
int var = 0;
do {
    cout << var;
} while(++var < 5);
```

### Решение

**Фрагмент 1 извежда:** `12345`

**Обяснение:**

- **var++** е постфиксен инкремент - сравнява старата стойност, после увеличава
- Итерация 1: проверява (0 < 5) → true, увеличава var=1, извежда 1
- Итерация 2: проверява (1 < 5) → true, увеличава var=2, извежда 2
- Итерация 3: проверява (2 < 5) → true, увеличава var=3, извежда 3
- Итерация 4: проверява (3 < 5) → true, увеличава var=4, извежда 4
- Итерация 5: проверява (4 < 5) → true, увеличава var=5, извежда 5
- Итерация 6: проверява (5 < 5) → false, цикълът спира

**Фрагмент 2 извежда:** `01234`

**Обяснение:**

- **do-while** изпълнява тялото поне веднъж, после проверява условието
- **++var** е префиксен инкремент - увеличава първо, после сравнява новата стойност
- Итерация 1: извежда 0, увеличава var=1, проверява (1 < 5) → true
- Итерация 2: извежда 1, увеличава var=2, проверява (2 < 5) → true
- Итерация 3: извежда 2, увеличава var=3, проверява (3 < 5) → true
- Итерация 4: извежда 3, увеличава var=4, проверява (4 < 5) → true
- Итерация 5: извежда 4, увеличава var=5, проверява (5 < 5) → false, цикълът спира

## 4) Указатели и паметна репрезентация

### Условие

Да се посочи какво ще изведе фрагментът. Допускаме, че `sizeof(unsigned int) == 4`.

```cpp
unsigned int x = 0x11335577;
unsigned char* ptr = (unsigned char*)&x;
++*ptr;
++*(ptr+1);
++ptr[2];
++3[ptr];
cout << hex << "0x" << x;
```

### Решение

**Изход:** `0x12345678`

**Обяснение:**

Нека разгледаме паметната репрезентация на `x = 0x11335577` (little-endian архитектура - Intel/AMD):

```
Адрес:     ptr+0  ptr+1  ptr+2  ptr+3
Байтове:   0x77   0x55   0x33   0x11
```

На little-endian системи младшият байт се съхранява на по-ниския адрес.

**Операции:**

- **++\*ptr** → увеличава байта на ptr+0: 0x77 → 0x78
- **++\*(ptr+1)** → увеличава байта на ptr+1: 0x55 → 0x56
- **++ptr[2]** → увеличава байта на ptr+2: 0x33 → 0x34 (ptr[2] е същото като \*(ptr+2))
- **++3[ptr]** → увеличава байта на ptr+3: 0x11 → 0x12 (3[ptr] е същото като ptr[3] или \*(ptr+3))

**След промените:**

```
Адрес:     ptr+0  ptr+1  ptr+2  ptr+3
Байтове:   0x78   0x56   0x34   0x12
```

Което в big-endian представяне (как се изписва числото) е: **0x12345678**

**Важни концепции:**

- **Pointer arithmetic:** ptr+i сочи i байта напред от ptr
- **Array notation:** ptr[i] е еквивалентно на \*(ptr+i)
- **Commutative notation:** i[ptr] е еквивалентно на ptr[i] (рядко използвано, но валидно)
- **Little-endian:** Байтовете се съхраняват в обратен ред

## 5) Препълване при събиране на char

### Условие

Нека `a` и `b` са променливи от тип `char`. Да се посочи какъв е проблемът в дадения по-долу фрагмент.

```cpp
char result = a + b;
```

Да се посочи възможен начин, чрез който може да се реши този проблем.

### Решение

**Проблем:** Възможно е резултатът от събирането на двете променливи да **не се побира в променлива от тип char**.

**Обяснение:**

- Допуснем `sizeof(char) == 1` (8 бита) и `char` е със знак (signed)
- Диапазон на `signed char`: -128 до 127
- Диапазон на `unsigned char`: 0 до 255

**Пример за препълване:**

- Нека `a = 100` и `b = 100`
- `a + b = 200`, което е извън диапазона [-128, 127]
- При присвояване към `char result`, стойността се "обвива" (wraparound): 200 - 256 = -56

**Решение на проблема:**

Използваме по-голям тип данни, който може да побере всички възможни стойности:

```cpp
int result = a + b;  // или short, long и т.н.
```

Или, ако искаме да запазим резултата в `char`, първо го проверяваме:

```cpp
int temp = a + b;
if (temp >= -128 && temp <= 127) {
    char result = static_cast<char>(temp);
} else {
    // Обработка на препълване
}
```

**Важни концепции:**

- **Integer promotion:** При аритметични операции, `char` автоматично се преобразува към `int`
- **Narrowing conversion:** Присвояването на `int` към `char` може да загуби информация
- **Overflow:** Препълването на знакови типове води до undefined behavior в C++

## 6) Обхождане на двумерен масив

### Условие

Нека са дадени следните дефиниции:

```cpp
const size_t size = 3;
char box[size][size] = {
    'a', 'b', 'c',
    'd', 'e', 'f',
    'g', 'h', 'i'
};
```

Масивът представлява:

```
a b c
d e f
g h i
```

Да се довършат фрагментите по-долу така, че да извеждат съответните последователности от букви.

**а) Трябва да извежда aei**

```cpp
for (int i = 0; i < size; i++)
    cout << box[______________][______________];
```

**б) Трябва да извежда ceg**

```cpp
for (int i = 0; i < size; i++)
    cout << box[______________][size__________];
```

**в) Трябва да извежда gec**

```cpp
for (int i = 0; i < size; i++)
    cout << box[size__________][______________];
```

**г) Трябва да извежда abcfihgd**

```cpp
for(int i = 0; i < size; ++i)
    cout << box[0][i];
for(int i = __________; i < size; __________)
    cout << box[i][size-1];
for(int i = size_______; i >= 0; --i)
    cout << box[size-1][i];
for(int i = size-2; i _____ 0; --i)
    cout << box[i][0];
```

### Решение

**а) Главен диагонал (aei):**

```cpp
for (int i = 0; i < size; i++)
    cout << box[i][i];
```

- Елементите на главния диагонал имат еднакви индекси: (0,0), (1,1), (2,2)
- a = box[0][0], e = box[1][1], i = box[2][2]

**б) Вторичен диагонал (ceg):**

```cpp
for (int i = 0; i < size; i++)
    cout << box[i][size-i-1];
```

- Вторичният диагонал: (0,2), (1,1), (2,0)
- c = box[0][2], e = box[1][1], g = box[2][0]
- Формула: колона = size - ред - 1

**в) Обратен вторичен диагонал (gec):**

```cpp
for (int i = 0; i < size; i++)
    cout << box[size-i-1][i];
```

- Същият диагонал като б), но в обратен ред
- g = box[2][0], e = box[1][1], c = box[0][2]
- Формула: ред = size - i - 1, колона = i

**г) Спирала по часовникова стрелка (abcfihgd):**

```cpp
// Горен ред (abc)
for(int i = 0; i < size; ++i)
    cout << box[0][i];

// Дясна колона без горния ъгъл (fi)
for(int i = 1; i < size; ++i)
    cout << box[i][size-1];

// Долен ред отдясно наляво без десния ъгъл (hg)
for(int i = size-2; i >= 0; --i)
    cout << box[size-1][i];

// Лява колона отдолу нагоре без ъглите (d)
for(int i = size-2; i > 0; --i)
    cout << box[i][0];
```

**Обяснение на спиралата:**

1. **Горен ред:** box[0][0], box[0][1], box[0][2] → abc
2. **Дясна колона (без горния ъгъл):** box[1][2], box[2][2] → fi
3. **Долен ред (отдясно наляво, без десния ъгъл):** box[2][1], box[2][0] → hg
4. **Лява колона (отдолу нагоре, без ъглите):** box[1][0] → d

Визуализация на обхождането:

```
a→b→c
↓   ↓
d   f
↑   ↓
g←h←i
```

## Ключови концепции

1. **Бързо степенуване** - O(log n) сложност чрез делене на степента на 2
2. **Числови литерали:**
   - Десетични: 10
   - Осмични: 010 (започва с 0)
   - Шестнадесетични: 0x10 (започва с 0x)
3. **Префиксен vs постфиксен инкремент:**
   - ++var: увеличава, после връща новата стойност
   - var++: връща старата стойност, после увеличава
4. **do-while:** Изпълнява тялото поне веднъж
5. **Little-endian:** Младшият байт е на по-нисък адрес
6. **Pointer arithmetic:** ptr[i] ≡ \*(ptr+i) ≡ i[ptr]
7. **Integer overflow:** Препълване при малки типове данни (char, short)
8. **Двумерен масив:**
   - Главен диагонал: box[i][i]
   - Вторичен диагонал: box[i][size-i-1]
   - Спирала: комбинация от ред/колона обхождания
