### 1) Изход на print функция

```cpp
void print(char* str) {
    char* ptr = str;
    while (*ptr != '\0') {
        *ptr = *ptr+1;
        ptr++;
    }
    std::cout << str;
}
void main() {
    char str[] = "ACE";
    print(str);
}
```

**Отговор:** `BDF`

**Обяснение:** Всеки символ се увеличава с 1 в ASCII таблицата:
- 'A' (65) → 'B' (66)
- 'C' (67) → 'D' (68)
- 'E' (69) → 'F' (70)

### 2) Променливи по референция и указател

```cpp
void func(int& x, int* y, int z){
    int a = 3;
    int b = 5;
    x = z - b;
    *y = 2 * z;
    z = x ? a + *y : 0;
}
void main() {
    int a = 2; int b = 4;
    func(b, &a, b);
    std::cout << a << endl;
    std::cout << b << endl;
}
```

**Отговор за `a`:** `8`

**Отговор за `b`:** `-1`

**Обяснение:**
- `x` е референция към `b` от main → `x = 4 - 5 = -1` → `b` става -1
- `*y` сочи към `a` от main → `*y = 2 * 4 = 8` → `a` става 8
- `z` е локална копие, промяната му не влияе на main

### 3) Цикъл с условие

```cpp
int total = 0;
for (int i = 2; i <= 10; ) {
    if (i % 3 == 0) {
        total = total + i;
    }
    i += 2;
}
std::cout << total << endl;
```

**Отговор:** `6`

**Обяснение:**
- `i = 2`: 2 % 3 ≠ 0, не добавяме
- `i = 4`: 4 % 3 ≠ 0, не добавяме
- `i = 6`: 6 % 3 = 0, `total = 6`
- `i = 8`: 8 % 3 ≠ 0, не добавяме
- `i = 10`: 10 % 3 ≠ 0, не добавяме
- `i = 12`: излизаме от цикъла

### 4) Условие за спиране на while цикъл

При какво условие ще спре да се изпълнява цикълът?

```cpp
while ((a || b) && (c || d)) {...}
```

**Варианти:**
- а) ако `!(a && b)` е истина
- б) ако `!a || !b || !c || !d` е истина
- в) ако `(!a && !b) || (!c && !d)` е истина
- г) ако `(!a || !b) && (!c || !d)` е истина
- д) нито един от изброените

**Отговор:** **в)**

**Обяснение:** 
Цикълът спира когато условието е `false`, т.е. когато:
```
!((a || b) && (c || d))
```
По закона на De Morgan:
```
!(a || b) || !(c || d)
= (!a && !b) || (!c && !d)
```

### 5) Обръщане на редове и колони в матрица

Да се попълнят фрагментите така, че функцията `reverseMatrixRows` да обръща местата на редовете на `mat` относно центъра, а функцията `reverseMatrixCols` да обръща местата на колоните.

#### Решение:

```cpp
void reverseMatrixRows(int** mat, int r, int c) {
    for (int i = 0; i < r / 2; ++i)
        for (int j = 0; j < c; ++j)
            swap(mat[i][j], mat[r-1-i][j]);
}

void reverseMatrixCols(int** mat, int r, int c) {
    for (int i = 0; i < r; ++i)
        for (int j = 0; j < c / 2; ++j)
            swap(mat[i][j], mat[i][c-1-j]);
}
```

**Обяснение:**
- **reverseMatrixRows**: Обменяме първия ред с последния, втория с предпоследния и т.н. до средата (`i < r/2`)
- **reverseMatrixCols**: Обменяме първата колона с последната, втората с предпоследната и т.н. до средата (`j < c/2`)

### 6) Рекурсивно обръщане на низ

Да се попълнят празните места в рекурсивната функция така, че `revStr` да обръща елементите на подаден като параметър низ `str`, които се намират на индекси в интервала `[start, end]`.

#### Решение:

```cpp
void revStr(string& str, unsigned start, unsigned end) {
    if (start >= end) {
        return;
    }
    swap(str[start], str[end]);
    revStr(str, start+1, end-1);
}
```

**Забележка:** Използването на `char*` вместо `string&` също е допустимо решение.

**Обяснение:**
- **Базов случай**: Ако `start >= end`, низът е обърнат (или е празен)
- **Рекурсивна стъпка**: Обменяме крайните символи и викаме функцията за по-малкия интервал `[start+1, end-1]`
