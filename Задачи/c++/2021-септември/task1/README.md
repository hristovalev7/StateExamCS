## 1А) Сумиране до нулев елемент

Какъв ще бъде изходът от изпълнението на следния фрагмент:

```cpp
int calc(int a[5])
{
    int sum = 8;
    for (int i = 0; a[i]; ++i)
        sum += i;
    return sum;
}
int a[7] = {1, 2, 3};
std::cout << calc(a);
```

### Примерно решение:

```
11
```

**Обяснение:**

- Масивът `a[7] = {1, 2, 3, 0, 0, 0, 0}` (останалите елементи се инициализират с 0)
- Цикълът върви докато `a[i]` е ненулево
- i=0: a[0]=1 (истина), sum = 8 + 0 = 8
- i=1: a[1]=2 (истина), sum = 8 + 1 = 9
- i=2: a[2]=3 (истина), sum = 9 + 2 = 11
- i=3: a[3]=0 (лъжа), цикълът спира
- Резултат: 11

## 1Б) Инкрементиране на символи в низ

Какъв ще бъде изходът от изпълнението на следния програмен фрагмент?

```cpp
char text[] = "hello", *p = text;
while (*p) std::cout << ++*p++;
```

### Примерно решение:

```
Отговор: в) ifmmp
```

**Обяснение:**

- Изразът `++*p++` означава: увеличи символа, на който сочи `p`, след това премести `p` напред
- Стъпки:
  - p→'h': извежда ++('h') = 'i', p++
  - p→'e': извежда ++('e') = 'f', p++
  - p→'l': извежда ++('l') = 'm', p++
  - p→'l': извежда ++('l') = 'm', p++
  - p→'o': извежда ++('o') = 'p', p++
  - p→'\0': цикълът спира
- Резултат: **ifmmp**

## 1В) Аритметика на указатели

Какво ще изведе следният фрагмент:

```cpp
int *pt;
int a[3] = {4, 19, 13};
pt = &a[1];
pt += 1;
std::cout << *pt << std::endl;
```

### Примерно решение:

```
13
```

**Обяснение:**

- `pt = &a[1]`: pt сочи към a[1], който е 19
- `pt += 1`: pt се премества с една позиция напред → сочи към a[2]
- `*pt`: дереференцираме → a[2] = 13
- Резултат: **13**

## 1Г) Копиране до отрицателно число

В дадените по-долу празни места попълнете какви ще бъдат стойностите на елементите на двата масива A и B след обръщението към функцията f:

```cpp
void f(int * arr1, const int * arr2)
{
    int *p1 = arr1;
    const int *p2 = arr2;
    while(*p2 >= 0)
    {
        *p1++ = *p2++;
    }
}
void main()
{
    int A[4] = {-1, -2, -3, -4};
    int B[4] = {10, 20, 30, -1};
    f(A, B);
}
```

### Примерно решение:

```
A[0] = 10
A[1] = 20
A[2] = 30
A[3] = -4

B[0] = 10
B[1] = 20
B[2] = 30
B[3] = -1
```

**Обяснение:**

- Функцията копира елементи от B в A докато не срещне отрицателно число в B
- Стъпки:
  - \*p2=10 (≥0): A[0]=10, p1++, p2++
  - \*p2=20 (≥0): A[1]=20, p1++, p2++
  - \*p2=30 (≥0): A[2]=30, p1++, p2++
  - \*p2=-1 (<0): цикълът спира
- A[3] остава непроменен (-4)
- B не се променя (защото arr2 е const)

## 1Д) Относителна позиция на две окръжности

Дадени са структури:

```cpp
struct Point {
    float x;
    float y;
};

struct Circle {
    Point center;
    float r;
};

enum RelativePosition {
    NO_COMMON_POINTS,  // без общи точки
    TOUCHING,          // допиращи се
    INTERSECTING,      // пресичащи се
    SAME               // съвпадат
};
```

Да се дефинира функция `findRelativePosition`, която определя относителната позиция на две окръжности.

### Примерно решение:

```cpp
#include <cmath>

struct Point {
    float x;
    float y;
};

struct Circle {
    Point center;
    float r;
};

enum RelativePosition {
    NO_COMMON_POINTS,
    TOUCHING,
    INTERSECTING,
    SAME
};

// Функция за изчисляване на разстояние между две точки
float distance(const Point& p1, const Point& p2) {
    float dx = p1.x - p2.x;
    float dy = p1.y - p2.y;
    return std::sqrt(dx * dx + dy * dy);
}

RelativePosition findRelativePosition(const Circle& c1, const Circle& c2) {
    float d = distance(c1.center, c2.center);
    float r1 = c1.r;
    float r2 = c2.r;

    const float EPSILON = 1e-6;  // За сравнение на float числа

    // Съвпадат: центровете съвпадат и радиусите са равни
    if (d < EPSILON && std::abs(r1 - r2) < EPSILON) {
        return SAME;
    }

    float sumRadii = r1 + r2;
    float diffRadii = std::abs(r1 - r2);

    // Допират се: d = r1 + r2 (външно) или d = |r1 - r2| (вътрешно)
    if (std::abs(d - sumRadii) < EPSILON || std::abs(d - diffRadii) < EPSILON) {
        return TOUCHING;
    }

    // Пресичат се: |r1 - r2| < d < r1 + r2
    if (d > diffRadii && d < sumRadii) {
        return INTERSECTING;
    }

    // Няма общи точки: d > r1 + r2 или d < |r1 - r2|
    return NO_COMMON_POINTS;
}
```

**Обяснение:**

За две окръжности с центрове C1, C2 и радиуси r1, r2:

- **d** = разстояние между центровете

**Случаи:**

1. **SAME (съвпадат):** d = 0 И r1 = r2
2. **TOUCHING (допиращи се):**
   - d = r1 + r2 (допират се външно)
   - d = |r1 - r2| (допират се вътрешно)

3. **INTERSECTING (пресичат се):** |r1 - r2| < d < r1 + r2

4. **NO_COMMON_POINTS (без общи точки):**
   - d > r1 + r2 (твърде отдалечени)
   - d < |r1 - r2| (едната е вътре в другата без допир)

**Важно:** Използваме EPSILON за сравнение на float числа, защото директното сравнение с `==` е ненадеждно поради грешки при закръгляне.
