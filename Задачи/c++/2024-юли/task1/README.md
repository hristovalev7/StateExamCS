## 1) Рекурсивна функция с char указател

```cpp
void print(char* p) {
    if (*(p++)) print(++p);
    std::cout << *(--p);
}

void main() {
    char str[] = "012345";
    print(str);
}
```

### Отговор: **531**

**Обяснение:**

Функцията работи рекурсивно, като "прескача" елементи при спускането и ги печата при връщането.

**Проследяване на изпълнението:**

- **Call 1:** p = &str[0]
  - `if (*(p++))` - проверява str[0]='0' (true), p става &str[1]
  - `print(++p)` - p става &str[2], извиква print(&str[2])
  - След return: `cout << *(--p)` - p е &str[2], става &str[1], печата **'1'**

- **Call 2:** p = &str[2]
  - `if (*(p++))` - проверява str[2]='2' (true), p става &str[3]
  - `print(++p)` - p става &str[4], извиква print(&str[4])
  - След return: `cout << *(--p)` - p е &str[4], става &str[3], печата **'3'**

- **Call 3:** p = &str[4]
  - `if (*(p++))` - проверява str[4]='4' (true), p става &str[5]
  - `print(++p)` - p става &str[6], извиква print(&str[6])
  - След return: `cout << *(--p)` - p е &str[6], става &str[5], печата **'5'**

- **Call 4:** p = &str[6] (т.е. '\0')
  - `if (*(p++))` - проверява str[6]='\0' (false), p става &str[7]
  - НЕ влиза в if, НЕ извиква рекурсия
  - `cout << *(--p)` - p е &str[7], става &str[6], печата '\0' (невидим символ)

**Резултат:** Печатат се в обратен ред: (нищо) от Call 4, '5' от Call 3, '3' от Call 2, '1' от Call 1 → **531**

## 2) Матрица и pointer arithmetic

```cpp
const size_t size = 3;
int matrix[size][size] = {
    1, 2, 3,
    4, 5, 6,
    7, 8, 9
};
```

### 2a)

```cpp
std::cout << matrix[1][2] << *matrix[2];
```

**Отговор: 67**

**Обяснение:**

- `matrix[1][2]` - елемент на ред 1, колона 2 = **6**
- `*matrix[2]` - matrix[2] е указател към ред 2 (т.е. &matrix[2][0]), \*matrix[2] е matrix[2][0] = **7**
- Изход: **67**

### 2б)

```cpp
std::cout << **matrix << *(*(matrix+2)+1);
```

**Отговор: 18**

**Обяснение:**

- `**matrix`:
  - `matrix` е указател към първия ред (`int (*)[3]`)
  - `*matrix` е първият ред (указател към matrix[0][0])
  - `**matrix` е matrix[0][0] = **1**
- `*(*(matrix+2)+1)`:
  - `matrix+2` е указател към ред 2 (т.е. &matrix[2])
  - `*(matrix+2)` е matrix[2], т.е. указател към matrix[2][0]
  - `*(matrix+2)+1` е &matrix[2][1]
  - `*(*(matrix+2)+1)` е matrix[2][1] = **8**

- Изход: **18**

## 3) Switch без break

```cpp
char symb = 'A';
switch(symb) {
    case 0 : std::cout << "0";
    case 65 : std::cout << "1";
    case 'a' : std::cout << "2";
    default : std::cout << "d";
}
```

### Отговор: **12d**

**Обяснение:**

- 'A' има ASCII код 65
- Съвпада с `case 65`, печата **"1"**
- НЯМА break, пада в `case 'a'` (fall-through), печата **"2"**
- НЯМА break, пада в `default` (fall-through), печата **"d"**
- Изход: **12d**

**Забележка:** Липсата на `break` води до изпълнение на всички следващи case-ове (fall-through).

## 4) While цикъл

```cpp
unsigned x = 8, y = 3;
while (x > 0) {
    if (x % y == 0) break;
    else x -= 1;
}
std::cout << x;
```

### Отговор: **6**

**Обяснение:**

Цикълът търси първото число <= 8, което се дели на 3:

- x=8: 8 % 3 = 2 ≠ 0, x става 7
- x=7: 7 % 3 = 1 ≠ 0, x става 6
- x=6: 6 % 3 = 0, **break**

Изход: **6**

## 5) Тернарен оператор

```cpp
unsigned a = 4, b = 8, c = 2;
std::cout << ((a > c) ? (b > a ? b : a) : c);
```

### Отговор: **8**

**Обяснение:**

Вложени тернарни оператори:

1. `a > c` → 4 > 2 → **true**
2. Влиза във втория израз: `b > a ? b : a`
3. `b > a` → 8 > 4 → **true**
4. Връща `b` = **8**

Изход: **8**

## 6) Insertion Sort - попълване на празни места

```cpp
void insert(int* arr, int index) {
    int key = arr[index];
    int j = ____________;
    while (_____________ && _____________) {
        _____________;
        j = j - 1;
    }
    arr[j + 1] = key;
}

void insertSort(int* arr, int size){
    for(int i = 1; i < size; i++) {
        insert(arr, i);
    }

```

### Решение:

```cpp
void insert(int* arr, int index) {
    int key = arr[index];
    int j = index - 1;
    while (j >= 0 && arr[j] > key) {
        arr[j + 1] = arr[j];
        j = j - 1;
    }
    arr[j + 1] = key;
}
```

**Обяснение:**

1. `int j = index - 1;` - започваме от елемента преди текущия
2. `while (j >= 0 && arr[j] > key)` - докато има елементи вляво и те са по-големи от ключа
3. `arr[j + 1] = arr[j];` - местим елемента една позиция надясно

**Як работи Insertion Sort:**

- Взима елемент на позиция `index`
- Сравнява го с елементите отляво (в сортираната част)
- Мести по-големите елементи надясно
- Вмъква елемента на правилното място

```cpp
    std::reverse(_____, ________);

```

**Пример:** При nums = {1, -2, 13, 40, 5} и k = 2, резултатът е {40, 5, 1, -2, 13}

### Решение:

```cpp
void rotateArray(int* nums, int k, int size) {
    if (size == 0 || k % size == 0)
        return;
    k %= size;
    std::reverse(nums, nums+size);
    std::reverse(nums, nums+k);
    std::reverse(nums+k, nums+size);
}
```

**Обяснение:**

Алгоритъм за ротация чрез три обръщания:

1. **Обръщаме целия масив:**
   - {1, -2, 13, 40, 5} → {5, 40, 13, -2, 1}

2. **Обръщаме първите k елемента:**
   - `std::reverse(nums, nums+k)` - обръща [0, k)
   - {5, 40, 13, -2, 1} → {40, 5, 13, -2, 1}

3. **Обръщаме останалите size-k елемента:**
   - `std::reverse(nums+k, nums+size)` - обръща [k, size)
   - {40, 5, 13, -2, 1} → {40, 5, 1, -2, 13} ✓

**Защо работи:**

- Първото обръщане "донася" последните k елемента в началото (но обърнати)
- Второто обръщане ги връща в правилен ред
- Третото обръщане връща останалите елементи в правилен ред

**Времева сложност:** O(n)  
**Пространствена сложност:** O(1) - in-place алгоритъм
