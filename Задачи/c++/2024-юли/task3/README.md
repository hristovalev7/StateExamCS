# Задача 3 - Дърво с произволен брой наследници

## Въведение

Разглеждаме (кореново) дърво с върхове, чиито стойности са цели числа, като всеки връх може да има произволен брой наследници, редът на които ще има значение – първия ще наричаме най-ляв, а последния – най-десен. „Ниво с номер 𝑛" наричаме списък от върховете в дървото, които са на разстояние 𝑛 от корена, подредени от ляво надясно. Казваме, че ниво в дървото „представя" даден вектор от цели числа, ако елементите във върховете в нивото образуват точно елементите на вектора.

---

## А) Дефиниция на TreeNode

### Условие

Да се дефинира тип `TreeNode` за представяне на връх от такова дърво.

### Решение

```cpp
struct TreeNode {
  int data;
  vector<TreeNode*> children;
  TreeNode(int d) : data(d) {}
};
```

**Обяснение:**

- Всеки връх съдържа `data` (цяло число) и вектор от указатели към децата си `children`
- Векторът `children` позволява произволен брой наследници
- Редът на децата в `children` определя подредбата отляво надясно
- Конструкторът инициализира `data`, а `children` е празен вектор по подразбиране

---

## Б) Функция findLevel

### Условие

Да се реализира функция

```cpp
int findLevel(const TreeNode* root, const vector<int>& numbers);
```

която по подаден указател към корен на такова дърво намира номер на ниво, представящо вектора `numbers`, или `-1`, ако такова ниво няма. Ако има повече от едно ниво с такива елементи, не е от значение кой номер ще се върне. Приемаме, че коренът определя ниво с номер 0.

### Решение

```cpp
int findLevel(const TreeNode* root, const vector<int>& numbers) {
  if (root == nullptr) {
    return -1;
  }

  vector<const TreeNode*> current = {root};
  int lvl = 0;

  while (!current.empty()) {
    // Събираме стойностите на текущото ниво
    vector<int> values;
    for (const TreeNode* node : current) {
      values.push_back(node->data);
    }

    // Проверяваме дали текущото ниво представя търсения вектор
    if (values == numbers) {
      return lvl;
    }

    // Подготвяме следващото ниво
    vector<const TreeNode*> next;
    for (const TreeNode* node : current) {
      for (const TreeNode* child : node->children) {
        next.push_back(child);
      }
    }

    current = next;
    lvl++;
  }

  return -1;
}
```

**Обяснение:**

- Използваме **BFS (Breadth-First Search)** обхождане по нива
- Векторът `current` съдържа всички върхове на текущото ниво
- За всяко ниво:
  1. Извличаме стойностите на всички върхове в `values`
  2. Сравняваме `values` с `numbers` - ако са равни, връщаме номера на нивото
  3. Създаваме следващото ниво `next`, като събираме всички деца на текущите върхове
- Ако преминем през всички нива без да намерим съвпадение, връщаме `-1`
- **Сложност:** O(n), където n е броят върхове в дървото

## В) Функция removeAllLevels

### Условие

Да се реализира функция

```cpp
void removeAllLevels(TreeNode* root, const vector<int>& numbers)
```

която по подаден указател към корен на дърво премахва всички нива с положителен номер, които представят вектора `numbers`. При премахване на връх, неговите преки наследници заемат неговото място и стават преки наследници на родителя му. Приемаме, че елементите на дървото са заделени с `new`.

### Решение

```cpp
void removeAllLevels(TreeNode* root, const vector<int>& numbers) {
  if (root == nullptr) {
    return;
  }

  vector<TreeNode*> current = {root};

  while (!current.empty()) {
    // Подготвяме следващото ниво
    vector<TreeNode*> next;
    for (TreeNode* node : current) {
      for (TreeNode* child : node->children) {
        next.push_back(child);
      }
    }

    // Ако няма следващо ниво, приключваме
    if (next.empty()) {
      break;
    }

    // Проверяваме дали следващото ниво съвпада с numbers
    vector<int> values;
    for (TreeNode* node : next) {
      values.push_back(node->data);
    }

    if (values == numbers) {
      // Премахваме следващото ниво
      for (TreeNode* node : current) {
        vector<TreeNode*> new_successors;

        // Събираме внуците (децата на децата)
        for (TreeNode* child : node->children) {
          for (TreeNode* grandchild : child->children) {
            new_successors.push_back(grandchild);
          }
          delete child; // Освобождаваме паметта за изтритото дете
        }

        // Заместваме децата с внуците
        node->children = new_successors;
      }
      // Не преминаваме към next, защото вече сме го премахнали
      // Продължаваме от current, за да проверим отново новите деца
    } else {
      // Преминаваме към следващото ниво
      current = next;
    }
  }
}
```

**Обяснение:**

- Отново използваме BFS обхождане, но този път проверяваме **следващото** ниво (`next`)
- Защо проверяваме `next` вместо `current`?
  - Функцията не трябва да премахва корена (само нива с положителен номер)
  - За да премахнем ниво, трябва да имаме достъп до родителите му
- Когато намерим ниво, което съвпада с `numbers`:
  1. За всеки родител в `current`:
     - Събираме внуците (децата на децата му) в `new_successors`
     - Изтриваме всички деца с `delete`
     - Заместваме `children` с `new_successors` (вдигаме внуците едно ниво нагоре)
  2. **Не** преминаваме към `next`, защото вече сме го премахнали
  3. Продължаваме от същото `current`, за да проверим отново новите деца
- Ако нивото не съвпада, просто преминаваме към него
- **Важно:** След премахване на ниво, НЕ увеличаваме `current`, защото новите деца могат отново да представят `numbers`
- **Сложност:** O(n·m), където n е броят върхове, m е броят премахвания (в най-лошия случай всички нива представят `numbers`)

---

## Забележки

1. **Проверка за край:** В `removeAllLevels` проверяваме `if (next.empty())` преди сравнението, за да избегнем безкраен цикъл
2. **Освобождаване на памет:** След `delete child` паметта е освободена, но указателят все още съществува - не го използваме след това
3. **Вдигане на внуци:** Алгоритъмът гарантира, че при премахване на ниво, всички негови деца се вдигат едно ниво нагоре
4. **Многократни премахвания:** Ако след премахване на едно ниво, новото следващо ниво също представя `numbers`, то също ще бъде премахнато
