# Задача 3 - C++ (Структури от данни)

## Дефиниция на структурата

```cpp
struct node {
    unsigned data;
    node* next; // Указател към следващ елемент в списъка или nullptr, ако няма такъв.
    node(unsigned data) : data(data), next(nullptr) {}
};
```

---

## 1) Копиране на елементи на нечетни позиции

Да се довърши кода на функцията `copyEveryOther`, така че тя да връща нов списък, в който се копират само елементите на нечетни позиции в списъка, сочен от `lst`, запазвайки техния ред. Приемаме, че позициите са номерирани от 1.

### Примерно решение:

```cpp
node* copyEveryOther(node* lst) {
    if (!lst) return nullptr;
    node* result = new node(lst->data);
    node* p = result;
    while ((lst = lst->next) && (lst = lst->next)) {
        p->next = new node(lst->data);
        p = p->next;
    }
    return result;
}
```

**Обосновка:**

- Започваме с първия елемент (позиция 1 - нечетна)
- На всяка итерация прескачаме два елемента: първият `lst->next` прескача елемента на четна позиция, вторият `lst->next` отива на следващия нечетен елемент
- Условието `&&` осигурява, че спираме, ако някой от скоковете води до `nullptr`

## 2) Времева сложност на copyEveryOther

Каква е времевата сложност на алгоритъма от 1) за списък с дължина 𝑛?

### Примерно решение:

```
Θ(n)
```

**Обосновка:** Обхождаме приблизително n/2 елемента, но това е линейна сложност - Θ(n).

## 3) Пространствена сложност на copyEveryOther

Каква е външната (auxiliary) пространствена сложност на алгоритъма от 1) за списък с дължина 𝑛? Във "външната сложност" НЕ СЕ включва пространството, консумирано от входните данни, нито това за изходните данни.

### Примерно решение:

```
Θ(1)
```

**Обосновка:** Използваме само константен брой допълнителни променливи (`result`, `p`). Новият списък е изходни данни и не се брои към auxiliary space.

## 4) Двоично наредено дърво (BST) - Inorder обхождане

Нека е дадено двоично наредено дърво. То използва стандартната организация, при която за всеки връх вляво от него има по-малки, а вдясно – по-големи елементи. В началото дървото е празно. След това последователно в него се добавят числата 5, 10, -5, 1 и 12. След това елементите на дървото се обхождат "ляво-корен-дясно" (inorder) и се извеждат на екрана.

### Примерно решение:

```
-5, 1, 5, 10, 12
```

**Обосновка:**
Дървото след вмъкване:

```
       5
      / \
    -5   10
      \    \
       1    12
```

Inorder обхождане (ляво-корен-дясно) дава сортирани елементи във възходящ ред.

## 5) Времева сложност на търсене в BST

Нека е дадено произволно двоично наредено дърво, съдържащо 𝑛 елемента. Каква е времевата сложност на търсенето на елемент в него в най-лошия случай?

### Примерно решение:

```
Θ(n)
```

**Обосновка:** В най-лошия случай дървото е дегенерирало (превърнато в списък), и трябва да обходим всички n елемента.

## 6) Сложности на операции с едносвързан списък

Да се посочат времевите сложности на следните операции с едносвързан списък с дължина 𝑛, който ни е подаден чрез указател към първия му елемент:

### Примерно решение:

```
Премахване на първия му елемент: Θ(1)
```

**Обосновка:** Директен достъп до първия елемент, константно време за промяна на указателя.

```
Премахване на последния му елемент: Θ(n)
```

**Обосновка:** Трябва да обходим целия списък, за да достигнем предпоследния елемент.

```
Проверка дали в списъка се съдържа дадено число K: Θ(n)
```

**Обосновка:** В най-лошия случай трябва да обходим всички елементи.

```
Добавяне на число на втора позиция в списъка: Θ(1)
```

**Обосновка:** Директен достъп до първия елемент и константно време за вмъкване след него.
