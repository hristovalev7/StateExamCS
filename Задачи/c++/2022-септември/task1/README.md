# Задача 1 - C++

## 1) Оценка на изрази с масиви

Нека е дефиниран масивът:

```cpp
int arr[] = { 1, 2, 3 };
```

Срещу всеки от изразите да се посочи каква ще бъде неговата оценка.

### Примерно решение:

```cpp
arr[1] == *(arr+2)     // false
arr == &arr[0]         // true
(arr+1) == &arr[1]     // true
*arr == arr[0]         // true
```

## 3) Конкатенация на низове

Нека са дадени следните дефиниции:

```cpp
char s1[] = "Hello";
char s2[] = "world!";
char result[80];
```

Да се довърши програмният фрагмент, така че след изпълнението му в `result` да се съхрани коректното представяне на низа `"Hello world!"`.

### Примерно решение:

```cpp
strcpy(result, s1);
strcat(result, " ");
strcat(result, s2);
```

## 4) Рекурсивни функции за търсене на подниз

Да се довърши кодът на рекурсивните функции, така че `f` да проверява дали символният низ, сочен от `word`, се съдържа като подниз в `text`. За определеност считаме, че празният низ се съдържа във всеки друг.

### Примерно решение:

```cpp
bool g(const char* text, const char* word)
{
    if (!*word) return true;
    if (!*text) return false;
    if (*word != *text) return false;
    return g(text + 1, word + 1);
}

bool f(const char* text, const char* word)
{
    if (!*word) return true;
    if (!*text) return false;
    return g(text, word) ||
           f(text + 1, word);
}
```
