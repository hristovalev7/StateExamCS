# Задача 2 - C++

## 1) Голямата четворка (Rule of 3)

Освен конструктора по подразбиране (default constructor), кои други функции влизат в "голямата четворка" (функциите от т.нар. "rule-of-3")?

### Примерно решение:

```
• Копиращ конструктор (copy constructor)
• Копиращо присвояване (copy assignment / operator=)
• Деструктор (destructor)
```

## 2) Статично и динамично свързване

Нека е дадена дефиницията:

```cpp
class foo {
public:
    virtual void f() {};
    void g() {};
};
```

Срещу всеки от редовете, които извикват `f` или `g`, да се запише "статично" или "динамично" според вида свързване, който ще се използва за тях.

### Примерно решение:

```cpp
foo obj;
foo& ref = obj;
obj.f();  // статично
obj.g();  // статично
ref.f();  // динамично
ref.g();  // статично
```

## 3) Видимост при наследяване

Нека са дадени следните дефиниции:

```cpp
class base {
public: int a;
private: int b;
};
class derived : protected base { };
```

Да се посочи каква ще бъде видимостта на променливите `a` и `b` в класа `derived` – public, protected или private.

### Примерно решение:

```
• Видимост на a: protected
• Видимост на b: private (или "няма видимост в производния клас")
```

## 4) Абстрактни класове

Нека класът `X` е абстрактен. Срещу всяко от твърденията да се посочи "да" или "не" според това дали е вярно:

### Примерно решение:

```
• Могат да се създават обекти от тип X: не
• Могат да се създават референции (reference) към обекти от тип X: да
```

## 5) Статични членове

Нека е дадена следната дефиниция:

```cpp
struct s {
public:
    static int var;
    s() { var = 5; }
};
int s::var = 0;
```

Да се посочи какво ще изведе следният фрагмент:

```cpp
std::cout << '(' << s::var << ')';
s obj1;
obj1.var = 10;
s obj2;
std::cout << '-' << s::var << '-';
```

### Примерно решение:

```
(0)-5-
```

## 6) Чисто виртуални функции

Да се допълни дефиницията на класа `test`, така че функцията `f` да бъде чиста виртуална (pure-virtual) и класът да може коректно да се използва като основа на полиморфна йерархия.

### Примерно решение:

```cpp
class test {
public:
    virtual void f() = 0;
    virtual ~test() {}
};
```

## 7) Шаблони на класове

Да се допълни дефиницията на шаблона `Array`, така че функцията `test` да се компилира коректно и да извежда на стандартния изход `55`.

```cpp
void test() {
    Array<int> a;
    a.at(0) = 5;
    std::cout << a.at(0);
    Array<Array<int>> b;
    b.at(0) = a;
    std::cout << b.at(0).at(0);
}
```

### Примерно решение:

```cpp
template <typename T>
class Array {
    static const size_t size = 10;
    T data[size];
public:
    T& at(size_t index) {
        if (index >= size)
            throw std::out_of_range("error");
        return data[index];
    }
};
```
