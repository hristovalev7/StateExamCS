# Задача 3 - C++ (Свързани списъци и дървета)

## Дефиниция на структурата за списък

```cpp
struct node {
    int data;       // числов елемент
    node* next;     // следваща кутия в списъка или nullptr, ако няма
    node(int data, node* next = nullptr)
        : data(data), next(next)
    {}
};
```

---

## 1) Сортиране на списък във възходящ ред

Да се довърши кодът на функциите така, че `sortListAscending` да сортира в нарастващ ред елементите на списъка `lst`. Ако списъкът е празен, функцията да не прави нищо.

### Примерно решение:

```cpp
node* min(node* lst)
{
    node* result = lst;
    for (; lst; lst = lst->next) {
        if (result->data > lst->data)
            result = lst;
    }
    return result;
}

void sortListAscending(node* lst)
{
    while (lst) {
        swap(lst->data, min(lst)->data);
        lst = lst->next;
    }
}
```

**Обосновка:**

- **`min` функция:** Намира възела с минимална стойност в останалата част от списъка. Сравнява `result->data > lst->data`, за да намери по-малката стойност.
- **`sortListAscending`:** Използва selection sort алгоритъм - на всяка итерация намира минималния елемент в несортираната част и го разменя с текущия първи елемент. Цикълът продължава докато `lst` не стане `nullptr` (обходи всички елементи).

## 2) Анализ на функцията mystery

Разгледайте кода на функцията:

```cpp
void mystery(node* lst)
{
    while (lst && lst->next) {
        lst->data += lst->next->data;
        lst->data /= 2;
        node* tmp = lst->next;
        lst = lst->next = lst->next->next;
        delete tmp;
    }
}
```

Под дадения долу фрагмент да се напише точно какво ще изведе на стандартния изход:

```cpp
node* e = new node(56);
node* d = new node(20, e);
node* c = new node(10, d);
node* b = new node(4, c);
node* a = new node(2, b);
mystery(a);
while (a) {
    std::cout << "[" << a->data << "] -> ";
    a = a->next;
}
std::cout << "NULL";
```

### Примерно решение:

```
[3] -> [15] -> [56] -> NULL
```

**Обосновка:**

Началният списък: `[2] -> [4] -> [10] -> [20] -> [56] -> NULL`

Функцията `mystery` на всяка итерация:

1. Изчислява средното аритметично на текущия и следващия елемент
2. Премахва следващия елемент (компресира списъка)

Стъпки:

- **Итерация 1:** `a = (2 + 4) / 2 = 3`, премахва 4 → `[3] -> [10] -> [20] -> [56] -> NULL`
- **Итерация 2:** `a = (10 + 20) / 2 = 15`, премахва 20 → `[3] -> [15] -> [56] -> NULL`
- **Итерация 3:** `56` няма следващ елемент, спира

Резултат: `[3] -> [15] -> [56] -> NULL`

## 3) Копиране на BST в масив (Inorder)

Възлите на двоично дърво представяме чрез:

```cpp
struct tnode {
    int data;       // числов елемент
    tnode* left;    // ляв наследник
    tnode* right;   // десен наследник
    // указателите са nullptr, ако възелът няма съответния наследник
};
```

Да се попълнят празните места в кода на функцията `toArray`. Тя получава корена `t` на двоично наредено дърво. Функцията да копира елементите му в масива `out` така, че да са сортирани в нарастващ ред чрез обхождане ляво-корен-дясно (inorder).

### Примерно решение:

```cpp
int* toArray(tnode* t, int* out)
{
    if (!t) {
        return out;
    }
    else {
        int* p = toArray(t->left, out);
        *p = t->data;
        return toArray(t->right, p + 1);
    }
}
```

**Обосновка:**

- **Базов случай `if (!t)`:** Ако дървото е празно, връщаме текущата позиция в масива без промени.
- **Рекурсивен случай:**
  1. `toArray(t->left, out)` - обхождаме лявото поддърво, записваме елементите и получаваме указател `p` към следващата свободна позиция
  2. `*p = t->data` - записваме корена на текущата позиция
  3. `toArray(t->right, p + 1)` - обхождаме дясното поддърво, започвайки от позицията след корена
- **Inorder обхождане** (ляво-корен-дясно) на BST винаги дава сортирани елементи във възходящ ред.
