## 1) Bubble sort с изход на всяка итерация

Дадена е дефиницията:

```cpp
void print(int* arr, int size) {
    for (int i = 0; i < size; ++i)
        cout << arr[i] << ";";
    cout << "\n";
}
```

Какво ще изведе на стандартния изход даденият по-долу фрагмент?

```cpp
const int size = 5;
int arr[] = { 5, 10, -1, 5, 6 };
for (int i = 0; i < size; ++i) {
    for (int j = 1; j < size; ++j) {
        if (arr[j-1] < arr[j]) {
            swap(arr[j-1], arr[j]);
        }
    }
    print(arr, size);
}
```

### Примерно решение:

```
На ред 1 извежда: 10;5;5;6;-1;
На ред 2 извежда: 10;5;6;5;-1;
На ред 3 извежда: 10;6;5;5;-1;
На ред 4 извежда: 10;6;5;5;-1;
На ред 5 извежда: 10;6;5;5;-1;
```

**Обяснение:** Това е модифициран bubble sort, който "избутва" най-големите елементи наляво (вместо надясно). След 3-та итерация масивът е сортиран и вече не се променя.

## 2) Функция за главни букви

Какво трябва да се попълни на мястото на коментара в `toUpper`, така че ако на функцията се подаде малка латинска буква, тя да връща съответната главна, а всички други символи да връща непроменени?

```cpp
char toUpper(char c) {
    return /* какво трябва да има тук? */ ;
}
```

### Примерно решение:

```
Отговор: Г) (c >= 'a' && c <= 'z') ? (c - 'a' + 'A') : c
```

```cpp
char toUpper(char c) {
    return (c >= 'a' && c <= 'z') ? (c - 'a' + 'A') : c;
}
```

**Обяснение:** Използваме `&&` (логическо И), за да проверим дали `c` е малка буква. Разстоянието между малка и главна буква е `'a' - 'A'`, затова изваждаме `'a'` и добавяме `'A'`.

## 3) Взаимно рекурсивни функции за четност

Да се попълнят празните места в дефинициите на функциите така, че `isOdd` да връща истина тогава и само тогава, когато подаденото число е нечетно, а `isEven` — когато то е четно.

### Примерно решение:

```cpp
bool isEven(unsigned int);

bool isOdd(unsigned int n) {
    if (n == 0) return false;
    if (n == 1) return true;
    return isEven(n - 1);
}

bool isEven(unsigned int n) {
    if (n == 0) return true;
    if (n == 1) return false;
    return isOdd(n - 1);
}
```

**Обяснение:** 0 е четно число, 1 е нечетно. Намаляваме числото с 1 и проверяваме обратното свойство (нечетно → четно и обратно).

## 4) Изход от различни фрагменти

### Фрагмент 1: Битово изместване

```cpp
for (int i = 0; i < 9; ++i)
    cout << (1 << i) << ";";
```

**Изход:**

```
1;2;4;8;16;32;64;128;256;
```

**Обяснение:** `1 << i` е степен на 2 (1, 2, 4, 8, 16...).

---

### Фрагмент 2: Switch без break

```cpp
switch(5 % 2) {
    case 0:
        std::cout << "0";
    case 1:
        std::cout << "1";
    default:
        std::cout << "x";
}
```

**Изход:**

```
1x
```

**Обяснение:** `5 % 2 = 1`, влизаме в `case 1`, но липсва `break`, затова изпълнява и `default`. Извежда "1" и "x".

---

### Фрагмент 3: Continue при i == 3

```cpp
for (int i = 0; i < 5; ++i) {
    if ( ! (i - 3))
        continue;
    std::cout << i;
}
```

**Изход:**

```
0124
```

**Обяснение:** `!(i - 3)` е истина само когато `i == 3`. При `i = 3` се прескача `cout`, за останалите се извежда `i`.

### Фрагмент 4: Указатели и нулев елемент

```cpp
int arr[] = { 1, 2, 3, 4, 0 };
*(arr + 2) *= 10;
for (int* p = arr; *p; p++)
    std::cout << *p << ";";
```

**Изход:**

```
1;2;30;4;
```

**Обяснение:** `arr[2]` става 30. Цикълът спира при `*p == 0` (5-тия елемент), затова не се извежда последният елемент.
