# Задача 2 - C++ (Конструктори и деструктори)

## Дефиниции

```cpp
class A {
public:
    A() { cout << "A()\n"; }
    A(A&) { cout << "A(A&)\n"; }
    virtual ~A() { cout << "~A()\n"; }
    A& operator=(A&) {
        cout << "op=(A&)\n";
        return *this;
    }
};

class B : public A {
public:
    B() { cout << "B()\n"; }
    B(B&) { cout << "B(B&)\n"; }
    virtual ~B() { cout << "~B()\n"; }
    B& operator=(B&) {
        cout << "op=(B&)\n";
        return *this;
    }
};

void f(A b) { cout << "f(A)\n"; }
```

---

## Решения

### 1) `B d;`

```
A()
B()
```

**Обяснение:** Създава се обект от тип B. Първо се извиква конструкторът по подразбиране на базовия клас A, след това конструкторът на B.

---

### 2) `B copy = d;`

```
A()
B(B&)
```

**Обяснение:** Копиращ конструктор на B. Първо се извиква конструкторът по подразбиране на A (за базовата част), след това копиращият конструктор на B.

---

### 3) `A b = d;`

```
A(A&)
```

**Обяснение:** Object slicing - създава се обект от тип A чрез копиращия конструктор на A. Само базовата част на `d` се копира.

---

### 4) `A& ref = d;`

```
не извежда нищо
```

**Обяснение:** Създава се само референция към базовия клас. Не се извикват конструктори, защото не се създава нов обект.

---

### 5) `B arr[2];`

```
A()
B()
A()
B()
```

**Обяснение:** Създават се два обекта от тип B в масив. За всеки обект се извикват конструкторите по подразбиране на A и B последователно.

---

### 6) `f(d);`

```
A(A&)
f(A)
~A()
```

**Обяснение:** Функцията `f` приема параметър по стойност от тип A. При извикването се създава временен обект A чрез копиращия конструктор (object slicing), изпълнява се функцията, след което временният обект се унищожава.

---

### 7) `A* p = new B(d);`

```
A()
B(B&)
```

**Обяснение:** Създава се динамично обект от тип B чрез копиращия му конструктор. Първо се извиква конструкторът по подразбиране на A (за базовата част), след това копиращият конструктор на B.

---

### 8) `delete p;`

```
~B()
~A()
```

**Обяснение:** Тъй като деструкторът на A е виртуален, се извиква деструкторът на B (реалният тип на обекта), след което автоматично се извиква деструкторът на A.

---

### 9) `d = d;`

```
op=(B&)
```

**Обяснение:** Самоприсвояване на обект от тип B. Извиква се операторът за присвояване на B.

---

### 10) `ref = d;`

```
op=(A&)
```

**Обяснение:** `ref` е референция от тип A&, но сочи към обект от тип B. При присвояването се извиква операторът за присвояване на A (операторът не е виртуален), което води до object slicing - присвоява се само базовата част.
